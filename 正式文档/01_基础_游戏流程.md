# 01_基础_游戏流程.md

# 游戏流程

版本：v4.2

---

## 术语定义

| 术语 | 含义 |
|------|------|
| **局** | 一次完整的新游戏，从开局到通关或失败 |
| **关** | 局内的一个战斗节点，包含准备阶段和战斗阶段 |
| **地区** | 一组关卡的集合，含独立的敌人种类、可招募物种和背景美术 |
| **圈层** | 战场上按重量级划分的三个区域（内圈/中圈/外圈） |
| **红心** | 整局游戏的生命值，初始3颗，战斗失败扣除1颗，为0时整局游戏结束 |
| **人口** | 上阵单位的容量限制，由主角"领导力"属性决定 |
| **连携技** | 特定标签组合的单位同时在场时自动触发的特殊效果 |
| **生产** | 不参与战斗、在生产区持续产出金币的单位定位 |
| **上阵** | 编入战斗队伍、可在关卡中使用的单位定位 |
| **木天蓼叶** | 通用货币，用于商店购买、招募提升等 |
| **品质** | 兵种的稀有度等级（普通/高级/稀有），固定不可变，定义不同种族猫的整体品质 |
| **强化版** | 兵种从原版升级后的版本，技能效果提升，基础属性不变 |
| **机制标签** | 绑定兵种技能效果的标签（如 `poison`、`split`），用于圣物匹配 |

---

## 一、游戏总览

一局游戏由 **初始选择** + **3 个大关** 组成。每个大关包含若干小关 + 1 个 Boss。地图在开局时随机生成，类似《杀戮尖塔》的分支路径地图。

### 1.1 红心系统

玩家初始拥有 **3 颗红心**，代表整局游戏的生命值：
- 战斗失败时扣除 1 颗红心
- 红心为 0 时，整局游戏直接结束
- 红心显示在选关 UI 中间上方和战斗 UI 我方 UI 上方

### 1.2 核心循环

每关的流程为：**战斗准备 → 战斗 → 构筑 → 选关**，然后循环。

```
初始选择（选择初始单位）
  │
  ▼
┌─────────────────────────────────────────┐
│  第 N 关                                 │
│  │                                       │
│  ├─→ 战斗准备（布阵）                    │
│  ├─→ 战斗                               │
│  │    ├─ 胜利 → 继续                     │
│  │    └─ 失败 → 扣红心                   │
│  │         ├─ 红心>0 → 继续              │
│  │         └─ 红心=0 → 游戏结束          │
│  ├─→ 构筑（商店/祈福/事件）              │
│  └─→ 选关（选择下一关）                  │
│       │                                 │
│       └─→ 进入第 N+1 关                 │
└─────────────────────────────────────────┘
  │
  ▼
第 45 关（最终 Boss）──→ 游戏结束
```

### 1.2 地区分布

```
═══ 地区 1（第 1~15 关）═══
  第 15 关（Boss）──→ 选择招募 → 地区切换
  │
  ▼
═══ 地区 2（第 16~30 关）═══
  第 30 关（Boss）──→ 选择招募 → 地区切换
  │
  ▼
═══ 地区 3（第 31~45 关）═══
  第 45 关（最终 Boss）──→ 游戏结束
```

## 二、关卡系统

### 2.1 关卡结构

| 项目 | 数值 |
|------|------|
| 总关数 | 45 关（3 个地区 × 15 层，可配置） |
| Boss 关 | 3 次（每个地区最后一层） |
| 地区数 | 3 个 |
| 普通关 | 42 关 |

### 2.2 地区切换

- 每次 Boss 关后切换至下一地区
- 地区切换意味着：
  - 新的敌人种类
  - 新的可招募物种
  - 新的背景美术

### 2.3 关卡选择

每关结束后，玩家从**地图 UI** 中选择下一关。

地图上显示多个可选节点，节点上显示情报（取决于主角"街头情报"等级）：

| 街头情报等级 | 显示内容 |
|-------------|----------|
| Lv.0 | 不显示敌方信息 |
| Lv.1 | 模糊描述（"少量"/"大量"） |
| Lv.2 | 大致范围（"10-20只"） |
| Lv.3 | 精确数字 + 敌方首领头像 |

> **实现说明**：街头情报等级影响地图节点Tips浮窗中的敌人信息显示精度。情报等级越高，显示的敌人信息越详细。

### 2.4 关卡类型

| 类型 | 说明 |
|------|------|
| **普通战斗** | 标准环形战场战斗 |
| **精英战斗** | 更强的敌人，更好的奖励 |
| **商店** | 消耗木天蓼叶购买单位、道具、增益 |
| **随机事件** | 触发特殊剧情或选择，可能获得单位、资源、增益或减益 |
| **温泉** | 强制二选一：集体泡温泉（全体单位生命值回满） 或 猫薄荷精华（选择一名兵种从原版升至强化版，技能效果提升） |
| **Boss** | 大关最终首领战 |

### 2.5 Boss 关

**触发条件**：累计关卡数达到预设节点（15 / 30 / 45）

**Boss 关特殊规则**：
- 全员强制上阵：当前拥有的所有单位（含生产区/后勤单位）全部参战，无视人口限制
- 人口限制在 Boss 关暂时解除
- 所有单位出现在布阵界面，可自由摆放
- 生产区/后勤单位在 Boss 关的战斗属性与普通单位相同

**Boss 关结算**：
- 胜利后，所有单位（含在战斗中阵亡的）全部复活（伤亡重置）
- **稀有兵种三选一**：击败 Boss 后出现稀有品质兵种三选一选择界面（全游戏仅 Boss 关产出）
- **Boss 圣物**：击败 Boss 后获得 Boss 专属圣物（全游戏仅 Boss 关产出）
- 选择招募（对敌方兵种掷骰子招募）
- 切换至下一地区

**失败处理**：
- Boss 关失败 → 本局结束，进入结算界面

## 三、准备阶段玩法

准备阶段包含以下玩法系统：

| 系统 | 包装名 | 强制性 | 说明 |
|------|--------|--------|------|
| 祈愿/祝福 | **命运** | 强制 | 选择档次 + 祝福 + 消耗猫粮 |
| 随机事件 | **抉择** | 强制 | 二选一，低风险/高风险 |
| 商店交易 | **猫市** | 非强制 | 自由买卖 |

### 弹出优先级

同一关有多个准备事件时，按优先级从高到低依次弹出：

```
命运 20 > 抉择 10 > 猫市 0
```

所有强制事件结束后，若有猫市，玩家可自行选择是否参与。

## 四、战斗系统

### 4.1 环形战场

**战场结构**：
- 战场为一个环形擂台，分为三个区域层级：

| 区域 | 允许进入的单位 | 区域大小 |
|------|---------------|----------|
| 内圈 | 重量级 | 小圈 |
| 中圈 | 中量级 | 中圈 |
| 外圈 | 轻量级 | 大圈 |

- 每个区域按重量级限制可进入的单位类型

**看板位置**：
- 我方看板固定在外圈之外的"后方区"
- 敌方看板固定在对面外圈之外的"后方区"
- 看板有独立的位置，不参与圈层划分

### 4.2 布阵规则（破阵模式）

**敌方布阵**：
- 敌人阵型为预设数据，由关卡配置决定
- 玩家进入布阵界面时，敌方单位已全部摆放完毕（破阵模式）
- 玩家可查看敌方所有单位的位置、类型

**我方布阵**：
- 战场为环形（横向椭圆圆环），分内中外三圈
- 玩家将上阵区的单位拖拽到对应圈层：
  - 重量级 → 内圈
  - 中量级 → 中圈
  - 轻量级 → 外圈
- 拖拽时绿色高亮表示可放置，红色高亮表示不可放置
- 布阵有时间限制或无限时，取决于关卡设定

> **圈层拜访限制**：圈层只有拜访限制（部署时必须放到对应圈层），没有移动限制（战斗中单位可以自由移动到任意圈层）。

**人口限制**：
- 每个兵种占用人口数在 `fighter_config.json` 的 `populationCost` 字段中配置
- 当前人口上限由主角"领导力"属性决定

### 4.3 战斗流程

**战斗开始**：
- 布阵确认后进入战斗，所有单位按物理规则自动战斗
- 战斗为实时物理乱斗，非回合制
- 单位自动寻找最近敌人攻击

**看板规则**：

- 战斗阶段双方看板均休眠（不攻击、不可被攻击、无敌）
- 当一方猫全部阵亡后，该方看板激活（可被攻击、可攻击敌方）
- 一方看板激活后，另一方看板不会再激活

**看板属性**：
- 看板血量为100，受伤后不会回复
- 看板攻击力为5，攻速0.5（每2秒攻击1次），射程5m
- 看板攻击为远程自动攻击，优先攻击最近的敌方单位

### 4.4 战斗结算

**胜利条件**：敌方猫全部阵亡（我方看板未被摧毁）

**失败条件**：我方看板被摧毁

**资源获取**：
- 战斗胜利获得关卡奖励（按区域和节点类型：100~300），失败获得一半
- 根据敌方看板剩余血量百分比获得看板血量奖励（0~200个木天蓼叶）

**战斗后流程**：
```
战斗结束
  ├─ 结算界面（奖励展示，失败也有关卡奖励）
  ├─ 招募环节（新增）
  │    ├─ 对方有几个兵种 → 出几张卡片
  │    ├─ 每张卡片掷骰子动画
  │    ├─ 彩色 = 可招募 / 黑白 = 不可招募
  │    ├─ 卡片信息：兵种名、头像、特性、人口占用、金币花费
  │    └─ 玩家选择招募 → 进入待上阵区
  ├─ 进入幕间（准备阶段）
  │    ├─ 命运/抉择/猫市（现有）
  │    ├─ 生产区管理（新增：可将待上阵区单位放入生产区）
  │    └─ 布阵（新增：拖拽上阵，受领导力限制）
  └─ 开始战斗
```

## 五、单位系统

### 5.1 单位属性

| 属性 | 说明 |
|------|------|
| 名称 | 单位显示名 |
| 物种 | 猫/犬/鸟/其他 |
| 重量级标签 | 轻量级/中量级/重量级（可多个） |
| 品质 | 普通/高级/稀有（固定不可变，定义不同种族猫的整体品质） |
| 类型标签 | 坦克/战士/灵能（可多个） |
| 人口占用 | 在 fighter_config.json 中配置 |
| 生命值 | 生命上限（强化不改变） |
| 攻击力 | 每次攻击伤害（强化不改变） |
| 攻击速度 | 攻击频率（强化不改变） |
| 移动速度 | 移动快慢（强化不改变） |
| 攻击距离 | 攻击范围（强化不改变） |

### 5.2 兵种技能

- 每个兵种拥有一个固定技能（原版和强化版效果不同）
- 技能在战斗中按触发条件生效
- 部分技能为光环效果，对全场所有匹配单位生效
- 技能在单位死亡后失效
- 强化版技能在原版基础上有明显提升（触发概率提升、机制新增、效果翻倍等）
- 技能效果与品质强相关：普通品质技能朴素，高级品质技能有机制组合，稀有品质技能为强力联动效果
- 技能体系详见 `03_基础_战斗技能Buff系统.md` 第五节
- 具体兵种技能详见 `401_单位_兵种设计.md` 第六节

### 5.3 标签系统

- 每个兵种携带若干机制标签（如：`poison`、`freeze`、`split`、`bounce`）
- 标签用于圣物匹配和技能联动判定
- 详见 `03_基础_战斗技能Buff系统.md` 第五节和第六节

### 5.4 连携技

**触发条件**：
- 特定标签组合的单位同时在场时，自动触发连携效果
- 例：场上同时存在"`freeze`"标签单位和"`burn`"标签单位时，触发冰火联动效果

**效果类型**：
- 属性增益（全员攻击力提升）
- 特殊攻击（对敌方全体造成一次伤害）
- 控制效果（敌方全体减速）
- 召唤效果（召唤临时单位）

**连携技在战斗开始前预览**：
- 布阵界面显示当前阵容可触发的连携技列表
- 帮助玩家决策阵容搭配

### 5.5 单位获取

| 获取方式 | 说明 |
|----------|------|
| 战斗招募 | 战斗胜利后，对敌方兵种掷骰子招募（品质按概率分布） |
| 商店购买 | 在猫市购买兵种 |
| 事件获取 | 关卡间随机事件可能触发单位加入 |
| 初始单位 | 每局开始，玩家拥有固定初始单位 |
| Boss关三选一 | 击败Boss后从三个稀有品质兵种中选择一个 |

> **品质概率**：不同大关的招募池中，普通/高级/稀有品质兵种出现概率不同，越后期高级和稀有出现概率越高。详见 `401_单位_兵种设计.md` 第三节。

## 六、主角系统

### 6.1 主角定位

- 主角不上场战斗
- 主角在场边作为"总大将"存在
- 主角属性影响全局战斗和运营

### 6.2 主角属性

| 属性 | 说明 |
|------|------|
| 等级 | 通过战斗经验提升（经验值在 fighter_config.json 中配置） |
| 领导力 | 决定人口上限（初始 3，每级 +1，上限待定） |
| 街头情报 | 决定战前情报精度（Lv.0~3），影响地图节点敌人信息显示 |
| 咪格魅力 | 提升首领招募概率 |

> **实现说明**：主角属性存储在 PlayerData 中，战斗经验通过战斗胜利获得，经验值配置在 fighter_config.json 中。

### 6.3 主角技能树

- 每次升级获得 1 技能点
- 技能树包含三条分支，每条分支 5 个技能，共 15 个技能：

| 分支 | 效果方向 |
|------|----------|
| 武斗派 | 提升开场全体攻击力/攻速 |
| 防御派 | 提升看板血量/开场护盾 |
| 仁义派 | 降低招募难度/提升生产区产出 |

- 玩家可自由分配技能点

> **实现说明**：技能树数据存储在 leader_skill_config.json 中，玩家的技能点和已解锁技能存储在 PlayerData 中。

## 七、三区系统

单位分为三个区域管理：

| 区域 | 说明 |
|------|------|
| **待上阵区** | 免费持有，无代价，可随时放入上阵区或生产区 |
| **上阵区** | 占用领导力人口，可拖拽部署到战场 |
| **生产区** | 不可逆，放入后固定产出金币，只做背景图+数据 |

### 7.1 待上阵区

- 战斗招募获得的单位默认进入待上阵区
- 商店购买的单位也进入待上阵区
- 玩家可随时将待上阵区单位移入上阵区或生产区

### 7.2 上阵区

- 玩家将待上阵区单位拖入上阵区
- 上阵区单位可拖拽部署到战场
- 上阵区占用领导力人口，总人口不能超过领导力上限
- 拖回待上阵区释放人口

### 7.3 生产区

- 幕间可将任意待上阵区单位放入（**不可逆**，放入后无法移出）
- 固定产出与战斗力匹配的金币
- 只做背景图+数据，不做表现

> **重要规则**：生产区是单向操作，单位一旦放入生产区就无法移出。Boss关时生产区单位会强制上阵参战，但Boss关结束后会返回生产区。

## 八、领导力系统

- 主角属性，初始值 3
- UI 显示 N 个格子（N = 领导力值）
- 每个兵种占用人口数在 `fighter_config.json` 的 `populationCost` 字段中配置
- 拖拽上阵占格子，拖回清格子
- Boss 关解除限制

---

## 九、招募系统

战斗胜利后触发招募：

- 对方有几个兵种 → 出几张卡片
- 每张卡片掷骰子动画
- 彩色 = 可招募 / 黑白 = 不可招募
- 卡片信息：兵种名、头像、特性、人口占用、金币花费
- 玩家选择招募 → 进入待上阵区

---

## 十、重伤/回血规则

- 战斗受伤不回复
- 战斗胜利后全员回复 20% HP（Boss 关 100%）
- 0血单位下回合以 20% HP 回归待上阵区，可继续使用
- 温泉可全体满血或强化单个单位（原版→强化版，技能效果提升）

---

## 十一、道具与经济

### 11.1 货币

**木天蓼叶**：通用货币
- 获取途径：初始200、战斗结算（胜利全额/失败半额）、看板掉落、命运祈愿、抉择事件、生产区产出、猫市出售兵种
- 用途：商店购买、招募消耗、命运祈愿消耗、猫市刷新

### 11.2 道具

| 类型 | 说明 |
|------|------|
| 消耗品 | 一次性战斗增益（攻击药、护盾药等） |
| 装备品 | 装备给特定单位，持续生效（项圈、羽织等） |
| 特殊品 | 改变规则的道具（如"下一场战斗人口限制解除"） |

### 11.3 商店

- 商店为可选关卡类型
- 提供单位购买、道具购买、增益购买
- 商品随机刷新

## 十二、局外成长

### 12.1 声望系统

- 每局结束后，根据成绩获得"声望"
- 声望用于解锁：

| 解锁内容 | 说明 |
|----------|------|
| 新的初始单位选择 | 开局可选不同的初始单位 |
| 新的可招募物种 | 更多物种加入招募池 |
| 新的技能效果池 | 更多技能效果可用 |
| 外观/皮肤 | 装饰性内容 |

### 12.2 存档

- 战斗中不可存档
- 每关选择完成后自动存档
- 一局未完成可暂停，下次继续
- 放弃当前局返回主菜单时，当前局进度作废

## 十三、状态转移条件

### 13.1 正常流转

```
初始选择 ──→ 第 1 关（地图选择 → 准备阶段 → 战斗阶段）
第 N 关战斗结束 ──→ 第 N+1 关地图选择（N < 45）
第 45 关战斗结束 ──→ 游戏胜利
```

### 13.2 Boss 关流转

```
第 15/30 关战斗胜利 ──→ 地区切换 → 下一关地图选择
第 45 关战斗胜利 ──→ 游戏胜利
Boss 关战斗失败 ──→ 游戏结束
```

### 13.3 失败条件

```
敌方猫未全部死亡 + 我方猫全部死亡 → 战斗失败
  │
  ├─→ 扣除 1 颗红心
  │    ├─→ 红心 > 0：继续游戏
  │    └─→ 红心 = 0：整局游戏结束
  │
  └─→ Boss 关失败：无论红心数量，直接整局游戏结束
```

### 13.4 阵亡恢复

```
战斗结束 → 伤害不回复，HP 持久化
胜利后全员回复 20% HP（Boss 关 100%）
0血单位下回合以 20% HP 回归待上阵区，可继续使用
```

## 十四、构筑节奏总览

### 第一关（1~15层）

- 主要收集**普通品质兵种**，搭建基础阵容
- 少量**高级品质兵种**初次亮相，为后续转型埋下伏笔
- 无稀有品质兵种（非Boss极低概率），但有圣物（普通圣物），玩家开始围绕机制标签调整阵容
- 温泉抉择首次出现，决定是否开始投资强化（原版→强化版）
- 击败本关Boss获得**第一个稀有品质兵种**（三选一），构筑方向初定
- 获得Boss专属圣物

### 第二关（16~30层）

- 普通品质兵种仍有出现，部分天生强化，开始被高级逐步取代
- 高级品质兵种成为主力过渡，未强化高级兵不如强化普通兵
- 可获得圣物（普通圣物、高级圣物、少量稀有圣物）
- 获得Boss专属圣物

### 第三关（31~45层）

- 普通品质兵种基本退出舞台
- 高级品质兵种大量且多半自带强化，成为中坚力量
- 稀有品质兵种多次出现，配合圣物形成完全体联动
- 可获得圣物（高级圣物、少量稀有圣物）
- 最终构筑成型，迎接最终Boss战
- 获得Boss专属圣物

### 跨品质联动参考

不同品质兵种之间存在天然配合关系，确保普通和高级品质兵种在后期仍有上场价值：

| 联动组合 | 核心兵种 | 收益兵种 | 联动效果 |
|----------|---------|---------|---------|
| **霸体阵线** | 橘猫（普通） | 骑士猫（稀有） | 橘猫提供霸体+嘲讽 → 骑士猫提供群体减伤 |
| **中毒链** | 苍蝇猫（普通）+ 巫毒猫（高级） | — | 苍蝇猫上毒 → 巫毒猫弹射传播 → 全屏中毒 |
| **冰火联动** | 冰冰猫（高级） | 火球猫（高级） | 冰冻+灼烧=双倍破冰，双向触发 |
| **缠绕增益** | 森林猫（高级） | 精灵猫（稀有） | 森林猫缠绕 → 精灵猫无限叠加攻速/伤害 |
| **分裂弹射环** | 长矛猫（普通）+ 火球猫（高级） | 铀235猫（稀有） | 分裂↔弹射光环下的无限连锁 |

## 十六、单位数据结构

```
UnitConfig {
    unitId:         单位唯一 ID
    name:           显示名
    species:        物种（Cat / Dog / Bird / Other）
    weightClass:    重量级标签（Light / Medium / Heavy，可多个）
    populationCost: 人口消耗（在 fighter_config.json 中配置）
    rarity:         品质（0=普通/1=高级/2=稀有，固定不可变）
    enhanceVersion: 强化版本（0=原版/1=强化版）
    typeTags:       类型标签列表（如 ["tank"] 或 ["warrior", "tank"]）
    maxHp:          生命值（基础值，强化不改变）
    attack:         攻击力（基础值，强化不改变）
    attackSpeed:    攻击速度（基础值，强化不改变）
    moveSpeed:      移动速度（基础值，强化不改变）
    attackRange:    攻击距离（基础值，强化不改变）
    targetPriority: 默认目标选择（强化不改变）
    skillId:        技能 ID（原版和强化版对应不同技能效果）
    mechanismTags:  机制标签列表（如 ["poison", "freeze"]，用于圣物系统匹配）
    tags:           通用标签列表（如 ["cat", "melee"]）
    avatarId:       外观 ID
}
```
