# 游戏流程

版本：v3.1

---

## 术语定义

| 术语 | 含义 |
|------|------|
| **局** | 一次完整的新游戏，从开局到通关或失败 |
| **关** | 局内的一个战斗节点，包含准备阶段和战斗阶段 |
| **地区** | 一组关卡的集合，含独立的敌人种类、可招募物种和背景美术 |
| **圈层** | 战场上按重量级划分的三个区域（内圈/中圈/外圈） |
| **看板** | 战场后方的大型单位，拥有极高血量和可观攻击力 |
| **人口** | 上阵单位的容量限制，由主角"领导力"属性决定 |
| **连携技** | 特定标签组合的单位同时在场时自动触发的特殊效果 |
| **生产** | 不参与战斗、在生产区持续产出金币的单位定位 |
| **上阵** | 编入战斗队伍、可在关卡中使用的单位定位 |
| **木天蓼叶** | 通用货币，用于商店购买、招募提升等 |

---

## 一、游戏总览

一局游戏由 **初始选择** + **3 个大关** 组成。每个大关包含若干小关 + 1 个 Boss。地图在开局时随机生成，类似《杀戮尖塔》的分支路径地图。

### 1.1 核心循环

每关的流程为：**战斗准备 → 战斗 → 构筑 → 选关**，然后循环。

```
初始选择（选择初始单位）
  │
  ▼
┌─────────────────────────────────────────┐
│  第 N 关                                 │
│  │                                       │
│  ├─→ 战斗准备（布阵）                    │
│  ├─→ 战斗                               │
│  ├─→ 构筑（商店/祈福/事件）              │
│  └─→ 选关（选择下一关）                  │
│       │                                 │
│       └─→ 进入第 N+1 关                 │
└─────────────────────────────────────────┘
  │
  ▼
第 50 关（最终 Boss）──→ 游戏结束
```

### 1.2 地区分布

```
═══ 地区 1（第 1~15 关）═══
  第 15 关（Boss）──→ 选择招募 → 地区切换
  │
  ▼
═══ 地区 2（第 16~30 关）═══
  第 30 关（Boss）──→ 选择招募 → 地区切换
  │
  ▼
═══ 地区 3（第 31~45 关）═══
  第 45 关（最终 Boss）──→ 游戏结束
```

## 二、关卡系统

### 2.1 关卡结构

| 项目 | 数值 |
|------|------|
| 总关数 | 45 关（3 个地区 × 15 层，可配置） |
| Boss 关 | 3 次（每个地区最后一层） |
| 地区数 | 3 个 |
| 普通关 | 42 关 |

### 2.2 地区切换

- 每次 Boss 关后切换至下一地区
- 地区切换意味着：
  - 新的敌人种类
  - 新的可招募物种
  - 新的背景美术

### 2.3 关卡选择

每关结束后，玩家从**地图 UI** 中选择下一关。

地图上显示多个可选节点，节点上显示情报（取决于主角"街头情报"等级）：

| 街头情报等级 | 显示内容 |
|-------------|----------|
| Lv.0 | 不显示敌方信息 |
| Lv.1 | 模糊描述（"少量"/"大量"） |
| Lv.2 | 大致范围（"10-20只"） |
| Lv.3 | 精确数字 + 敌方首领头像 |

> **实现说明**：街头情报等级影响地图节点Tips浮窗中的敌人信息显示精度。情报等级越高，显示的敌人信息越详细。

### 2.4 关卡类型

| 类型 | 说明 |
|------|------|
| **普通战斗** | 标准环形战场战斗 |
| **精英战斗** | 更强的敌人，更好的奖励 |
| **商店** | 消耗木天蓼叶购买单位、道具、增益 |
| **随机事件** | 触发特殊剧情或选择，可能获得单位、资源、增益或减益 |
| **温泉** | 二选一：回复所有单位50%生命值 或 永久提升指定单位全属性50% |
| **Boss** | 大关最终首领战 |

### 2.5 Boss 关

**触发条件**：累计关卡数达到预设节点（15 / 30 / 50）

**Boss 关特殊规则**：
- 全员强制上阵：当前拥有的所有单位（含生产区）全部参战
- 人口限制在 Boss 关暂时解除
- 所有单位出现在布阵界面，可自由摆放
- 生产区单位在 Boss 关的战斗属性与普通单位相同

**Boss 关结算**：
- 胜利后，所有单位（含在战斗中阵亡的）全部复活
- 给予 Boss 关专属奖励（解锁新物种 / 看板能力提升 / 稀有道具）
- 选择招募（对敌方兵种掷骰子招募）
- 切换至下一地区

**失败处理**：
- Boss 关失败 → 本局结束，进入结算界面

## 三、准备阶段玩法

准备阶段包含以下玩法系统：

| 系统 | 包装名 | 强制性 | 说明 |
|------|--------|--------|------|
| 祈愿/祝福 | **命运** | 强制 | 选择档次 + 祝福 + 消耗猫粮 |
| 随机事件 | **抉择** | 强制 | 二选一，低风险/高风险 |
| 商店交易 | **猫市** | 非强制 | 自由买卖 |

### 弹出优先级

同一关有多个准备事件时，按优先级从高到低依次弹出：

```
命运 20 > 抉择 10 > 猫市 0
```

所有强制事件结束后，若有猫市，玩家可自行选择是否参与。

## 四、战斗系统

### 4.1 环形战场

**战场结构**：
- 战场为一个环形擂台，分为三个区域层级：

| 区域 | 允许进入的单位 | 区域大小 |
|------|---------------|----------|
| 内圈 | 重量级 | 小圈 |
| 中圈 | 中量级 | 中圈 |
| 外圈 | 轻量级 | 大圈 |

- 每个区域按重量级限制可进入的单位类型

**看板位置**：
- 我方看板固定在外圈之外的"后方区"
- 敌方看板固定在对面外圈之外的"后方区"
- 看板有独立的位置，不参与圈层划分

### 4.2 布阵规则（破阵模式）

**敌方布阵**：
- 敌人阵型为预设数据，由关卡配置决定
- 玩家进入布阵界面时，敌方单位已全部摆放完毕（破阵模式）
- 玩家可查看敌方所有单位的位置、类型

**我方布阵**：
- 战场为环形（横向椭圆圆环），分内中外三圈
- 玩家将上阵区的单位拖拽到对应圈层：
  - 重量级 → 内圈
  - 中量级 → 中圈
  - 轻量级 → 外圈
- 拖拽时绿色高亮表示可放置，红色高亮表示不可放置
- 布阵有时间限制或无限时，取决于关卡设定

> **圈层拜访限制**：圈层只有拜访限制（部署时必须放到对应圈层），没有移动限制（战斗中单位可以自由移动到任意圈层）。

**人口限制**：
- 每个兵种占用人口数在 `fighter_config.json` 的 `populationCost` 字段中配置
- 当前人口上限由主角"领导力"属性决定

### 4.3 战斗流程

**战斗开始**：
- 布阵确认后进入战斗，所有单位按物理规则自动战斗
- 战斗为实时物理乱斗，非回合制
- 单位自动寻找最近敌人攻击

**看板规则**：

| 阶段 | 我方看板状态 | 敌方看板状态 |
|------|-------------|-------------|
| 我方小兵存活中 | 休眠（不攻击、不可被攻击、无敌） | 休眠 |
| 我方小兵全灭 | 激活：开始攻击，可被敌方攻击 | 休眠 |
| 敌方小兵全灭 | 激活 | 激活：可被我方攻击，被攻击时掉落货币 |

**看板属性**：
- 看板拥有极高血量
- 看板拥有可观攻击力（前期可有效清理残血敌人，但无法独挡大军）
- 看板攻击为远程自动攻击，优先攻击最近的敌方单位

### 4.4 战斗结算

**胜利条件**：敌方小兵全灭 + 敌方看板被摧毁

**失败条件**：我方小兵全灭 + 我方看板被摧毁

**资源获取**：
- 攻击敌方看板期间，看板持续掉落货币（木天蓼叶）
- 摧毁看板时，爆发大量货币

**战斗后流程**：
```
战斗胜利
  ├─ 结算界面（奖励展示）
  ├─ 招募环节（新增）
  │    ├─ 对方有几个兵种 → 出几张卡片
  │    ├─ 每张卡片掷骰子动画
  │    ├─ 彩色 = 可招募 / 黑白 = 不可招募
  │    ├─ 卡片信息：兵种名、头像、特性、人口占用、金币花费
  │    └─ 玩家选择招募 → 进入待上阵区
  ├─ 进入幕间（准备阶段）
  │    ├─ 命运/抉择/猫市（现有）
  │    ├─ 生产区管理（新增：可将待上阵区单位放入生产区）
  │    └─ 布阵（新增：拖拽上阵，受领导力限制）
  └─ 开始战斗
```

## 五、单位系统

### 5.1 单位属性

| 属性 | 说明 |
|------|------|
| 名称 | 单位显示名 |
| 物种 | 猫/犬/鸟/其他 |
| 重量级标签 | 轻量级/中量级/重量级（可多个） |
| 人口占用 | 在 fighter_config.json 中配置 |
| 生命值 | 生命上限 |
| 攻击力 | 每次攻击伤害 |
| 攻击速度 | 攻击频率 |
| 移动速度 | 移动快慢 |

### 5.2 被动技能

- 每个单位拥有一个被动技能
- 被动技能在战斗中持续生效
- 部分被动技能标记为"不分敌我"，对全场所有单位生效
- 被动技能在单位死亡后失效

### 5.3 标签系统

- 每个单位携带若干标签（如：猫科、飞行、近战、远程）
- 标签用于连携技触发判定

### 5.4 连携技

**触发条件**：
- 特定标签组合的单位同时在场时，自动触发连携效果
- 例：场上同时存在"飞行"标签单位和"犬科"标签单位时，触发"天降正义"效果

**效果类型**：
- 属性增益（全员攻击力提升）
- 特殊攻击（对敌方全体造成一次伤害）
- 控制效果（敌方全体减速）
- 召唤效果（召唤临时单位）

**连携技在战斗开始前预览**：
- 布阵界面显示当前阵容可触发的连携技列表
- 帮助玩家决策阵容搭配

### 5.5 单位获取

| 获取方式 | 说明 |
|----------|------|
| 战斗招募 | 战斗胜利后，对敌方兵种掷骰子招募 |
| 商店购买 | 在猫市购买兵种 |
| 事件获取 | 关卡间随机事件可能触发单位加入 |
| 初始单位 | 每局开始，玩家拥有固定初始单位 |

## 六、主角系统

### 6.1 主角定位

- 主角不上场战斗
- 主角在场边作为"总大将"存在
- 主角属性影响全局战斗和运营

### 6.2 主角属性

| 属性 | 说明 |
|------|------|
| 等级 | 通过战斗经验提升（经验值在 fighter_config.json 中配置） |
| 领导力 | 决定人口上限（初始 3，每级 +1，上限待定） |
| 街头情报 | 决定战前情报精度（Lv.0~3），影响地图节点敌人信息显示 |
| 咪格魅力 | 提升首领招募概率 |

> **实现说明**：主角属性存储在 PlayerData 中，战斗经验通过战斗胜利获得，经验值配置在 fighter_config.json 中。

### 6.3 主角技能树

- 每次升级获得 1 技能点
- 技能树包含三条分支，每条分支 5 个技能，共 15 个技能：

| 分支 | 效果方向 |
|------|----------|
| 武斗派 | 提升开场全体攻击力/攻速 |
| 防御派 | 提升看板血量/开场护盾 |
| 仁义派 | 降低招募难度/提升生产区产出 |

- 玩家可自由分配技能点

> **实现说明**：技能树数据存储在 leader_skill_config.json 中，玩家的技能点和已解锁技能存储在 PlayerData 中。

## 七、三区系统

单位分为三个区域管理：

| 区域 | 说明 |
|------|------|
| **待上阵区** | 免费持有，无代价，可随时放入上阵区或生产区 |
| **上阵区** | 占用领导力人口，可拖拽部署到战场 |
| **生产区** | 不可逆，放入后固定产出金币，只做背景图+数据 |

### 7.1 待上阵区

- 战斗招募获得的单位默认进入待上阵区
- 商店购买的单位也进入待上阵区
- 玩家可随时将待上阵区单位移入上阵区或生产区

### 7.2 上阵区

- 玩家将待上阵区单位拖入上阵区
- 上阵区单位可拖拽部署到战场
- 上阵区占用领导力人口，总人口不能超过领导力上限
- 拖回待上阵区释放人口

### 7.3 生产区

- 幕间可将任意待上阵区单位放入（**不可逆**，放入后无法移出）
- 0血单位获得"满目疮痍"debuff，不能上阵，只能放入生产区
- 固定产出与战斗力匹配的金币
- 只做背景图+数据，不做表现

> **重要规则**：生产区是单向操作，单位一旦放入生产区就无法移出。Boss关时生产区单位会强制上阵参战，但Boss关结束后会返回生产区。

## 八、领导力系统

- 主角属性，初始值 3
- UI 显示 N 个格子（N = 领导力值）
- 每个兵种占用人口数在 `fighter_config.json` 的 `populationCost` 字段中配置
- 拖拽上阵占格子，拖回清格子
- Boss 关解除限制

---

## 九、招募系统

战斗胜利后触发招募：

- 对方有几个兵种 → 出几张卡片
- 每张卡片掷骰子动画
- 彩色 = 可招募 / 黑白 = 不可招募
- 卡片信息：兵种名、头像、特性、人口占用、金币花费
- 玩家选择招募 → 进入待上阵区

---

## 十、重伤/回血规则

- 战斗受伤不回复
- 0血单位获得"满目疮痍"debuff，不能上阵
- 只有事件和被动技能能回血
- 0血单位的唯一用途是放入生产区

---

## 十一、道具与经济

### 11.1 货币

**木天蓼叶**：通用货币
- 获取途径：战斗胜利、攻击敌方看板、生产区产出、事件奖励
- 用途：商店购买、招募提升概率、特定事件消耗

### 11.2 道具

| 类型 | 说明 |
|------|------|
| 消耗品 | 一次性战斗增益（攻击药、护盾药等） |
| 装备品 | 装备给特定单位，持续生效（项圈、羽织等） |
| 特殊品 | 改变规则的道具（如"下一场战斗人口限制解除"） |

### 11.3 商店

- 商店为可选关卡类型
- 提供单位购买、道具购买、增益购买
- 商品随机刷新

---

## 十二、局外成长

### 12.1 声望系统

- 每局结束后，根据成绩获得"声望"
- 声望用于解锁：

| 解锁内容 | 说明 |
|----------|------|
| 新的初始单位选择 | 开局可选不同的初始单位 |
| 新的可招募物种 | 更多物种加入招募池 |
| 新的被动技能池 | 更多被动技能可用 |
| 外观/皮肤 | 装饰性内容 |

### 12.2 存档

- 战斗中不可存档
- 每关选择完成后自动存档
- 一局未完成可暂停，下次继续
- 放弃当前局返回主菜单时，当前局进度作废

---

## 十三、状态转移条件

### 13.1 正常流转

```
初始选择 ──→ 第 1 关（地图选择 → 准备阶段 → 战斗阶段）
第 N 关战斗结束 ──→ 第 N+1 关地图选择（N < 50）
第 50 关战斗结束 ──→ 游戏胜利
```

### 13.2 Boss 关流转

```
第 15/30 关战斗胜利 ──→ 地区切换 → 下一关地图选择
第 50 关战斗胜利 ──→ 游戏胜利
Boss 关战斗失败 ──→ 游戏结束
```

### 13.3 失败条件

```
我方小兵全灭 + 我方看板被摧毁 → 战斗失败
  │
  ├─→ Boss 关：本局结束
  └─→ 普通关：损失本次战斗单位（待定）
```

### 13.4 阵亡恢复

```
战斗结束 → 伤害不回复，HP 持久化
0血单位获得"满目疮痍"debuff，不能上阵，只能放入生产区
Boss 关战斗结束 → 所有单位复活
```

## 十四、关卡配置数据结构

```
LevelConfig {
    levelId:        关卡编号（1~50）
    regionId:       所属地区（1~3）
    isBoss:         是否 Boss 关
    difficulty:     难度系数
    enemyFormation: 敌方阵型配置
    levelType:      关卡类型（Battle / Shop / Event）
}
```

---

## 十五、单位数据结构

```
UnitConfig {
    unitId:         单位唯一 ID
    name:           显示名
    species:        物种（Cat / Dog / Bird / Other）
    weightClass:    重量级标签（Light / Medium / Heavy，可多个）
    populationCost: 人口消耗（在 fighter_config.json 中配置）
    maxHp:          生命值
    attack:         攻击力
    attackSpeed:    攻击速度
    moveSpeed:      移动速度
    passiveSkillId: 被动技能 ID
    tags:           标签列表（如 ["cat", "melee", "flying"]）
    avatarId:       外观 ID
}
```

---

## 十六、布阵数据结构
