# 兵种设计

版本：v3.0

---

## 一、系统概述

兵种是战斗的核心单位。本文档定义游戏中所有基础技能效果、联动规则、兵种配置及配套圣物。技能体系遵循"原子单元"设计原则——每种基础技能效果是不可再拆分的底层逻辑，兵种技能、圣物效果均通过这些原子单元组合实现。

**设计原则**：
- **数值不膨胀，机制做质变**：兵种成长不靠堆叠攻击力，而是通过技能联动来产生"配合倍率"
- **标签驱动**：每种技能效果绑定`mechanismTag`，圣物通过标签匹配增强对应机制
- **品质分层**：普通/高级/稀有品质决定了不同种族猫的整体品质，品质不随任何因素改变
- **理解简单，构筑有深度**：稀有度体系与强化规则一目了然，但圣物与稀有兵种提供了充足的 synergies 探索空间

### 1.1 技能效果总览

| 体系 | 包含效果 |
|------|---------|
| 控制体系 | 减速、缠绕、沉默、眩晕、冰冻、击退、击倒、击飞、嘲讽 |
| 异常伤害体系 | 灼烧、中毒 |
| 防御体系 | 治疗、分摊 |
| 增益体系 | 吸血、霸体 |
| 特殊效果 | 分裂、弹射、召唤 |

### 1.2 类型标签系统

每个猫拥有**类型标签**，用于体系划分和阵容搭配。当前定义三种标签：

| 标签 | 定位 | 典型特征 |
|------|------|---------|
| **坦克** | 前排承伤、嘲讽吸引火力 | 高生命值、霸体/减伤机制 |
| **战士** | 中排输出、混合功能 | 均衡属性、控制/输出兼备 |
| **灵能** | 后排输出/辅助、机制驱动 | 远程攻击、DOT/召唤/治疗等特殊机制 |

一般种族的猫只有一种标签，部分特殊种族的猫可能拥有多种标签。标签种类后续可扩充。

### 1.3 兵种属性参数说明

每个猫拥有以下基础属性参数，强化不改变这些参数：

| 参数 | 说明 | 单位 |
|------|------|------|
| **出战人口占用** | 上阵时消耗的领导力格子数 | 个 |
| **生命值** | 最大生命值 | 点 |
| **攻击力** | 单次攻击/技能的基础伤害 | 点 |
| **攻击速度** | 每秒攻击次数（0.5=每2秒1次，1=每秒1次，2=每秒2次） | 次/秒 |
| **移动速度** | 战场中的移动速度 | m/s |
| **攻击距离** | 可以发起攻击的最远距离 | m |
| **默认目标选择** | 自动攻击时的优先目标规则 | — |

## 二、稀有度体系

**稀有度不再是同一种族内的品质分级，而是定义不同种族猫的整体品质。** 某个种族的猫固定为普通、高级、稀有品质中的一种，不可改变。

| 品质 | 设计定位 | 基础属性水平 | 代表特征 |
|------|---------|-------------|---------|
| **普通** | 基础机制载体，前期的建队基石 | 较低 | 技能效果直接、易理解 |
| **高级** | 机制升级版，中期的主力核心 | 中等 | 技能触发更可控、更稳定 |
| **稀有** | 机制联动核心，构筑的终极引擎 | 较高 | 技能依赖场上其他单位的机制触发联动效果 |

> 品质不随任何因素改变。橘猫始终是普通品质，骑士猫始终是稀有品质。

### 2.1 品质差异总览

遵循"普通是机制载体 → 高级是combo基准 → 稀有是combo爽版"的原则，三种品质的兵种在以下维度呈现梯度差异：

| 维度 | 普通品质 | 高级品质 | 稀有品质 |
|------|---------|---------|---------|
| **基础属性** | 低（HP 20~100） | 中（HP 60~120） | 高（HP 8~150） |
| **人口占用** | 1~3 | 1~3 | 3~8 |
| **技能触发** | 概率触发，不稳定 | 定时/条件触发，稳定可控 | 联动触发，依赖场上机制 |
| **技能复杂度** | 单一机制 | 双机制组合 | 跨单位联动/光环效果 |
| **强化收益** | 触发概率提升/机制新增 | 效果翻倍/控制升级 | 光环范围扩展/无限叠加 |

## 四、强化系统

### 4.1 强化规则

同一品种下的猫，有**原版**和**强化版**两种形态。强化版的技能效果在原版基础上有明显提升。

| 版本 | 界面表现 | 说明 |
|------|---------|------|
| **原版** | 无特殊标记 | 基础技能效果 |
| **强化版** | 显示"强化"标签 | 技能效果提升 |

**强化规则：**
- 强化不改变该种族猫的品质（普通/高级/稀有）
- 强化不改变猫的基础属性参数（人口占用、生命值、攻击力、攻击速度、移动速度、攻击距离、默认目标选择）
- 每个猫只能强化一次（从原版→强化版）

强化在**温泉场景**的强制二选一中触发：

| 选项 | 效果 | 说明 |
|------|------|------|
| **选项A：集体泡温泉** | 全体单位生命值回满 | 当下安全 |
| **选项B：猫薄荷精华** | 选择一名兵种，将其从原版升至强化版 | 未来战力 |

**关键约束**：
- 此二选一不可兼得，选择后不可反悔
- 猫薄荷精华不可保留、不可带走，必须当场使用
- 只能对原版兵种使用（已强化兵种不可再次强化）

### 4.2 设计意图

强制玩家在"当下安全"与"未来战力"之间做出战略权衡。越是追求极限强度，越需要放弃恢复，增加后续关卡的风险。

## 五、被动系统（技能系统）

每个兵种拥有**一个固定技能**（原版和强化版效果不同），根据品质和机制设计。

### 5.1 技能与强化关系

- 强化不改变基础属性参数，只改变技能效果
- 维持兵种的核心辨识度，降低玩家认知负担

### 5.2 按品质的技能设计

| 品质 | 技能特点 | 示例 |
|------|---------|------|
| **普通** | 技能效果直接、易理解 | "攻击时有30%概率分裂出1个长矛" |
| **高级** | 技能触发更可控、更稳定 | "每10秒缠绕当前目标敌人2秒" |
| **稀有** | 强力联动技能，与特定机制深度绑定 | "场上每存在1名被缠绕的敌人时，攻速+10%，伤害+10%，可无限叠加" |

## 七、构筑节奏总览

### 第一关（1~15层）

- 主要收集**普通品质兵种**，搭建基础阵容
- 少量**高级品质兵种**初次亮相，为后续转型埋下伏笔
- 无稀有品质兵种（非Boss极低概率），但有圣物（普通圣物），玩家开始围绕机制标签调整阵容
- 温泉抉择首次出现，决定是否开始投资强化
- 击败本关Boss获得**第一个稀有品质兵种**（三选一），构筑方向初定
- 获得Boss专属圣物

### 第二关（16~30层）

- 普通品质兵种仍有出现，部分天生强化，开始被高级逐步取代
- 高级品质兵种成为主力过渡，未强化高级兵不如强化普通兵
- 可获得圣物（普通圣物、高级圣物、少量稀有圣物）
- 获得Boss专属圣物

### 第三关（31~45层）

- 普通品质兵种基本退出舞台
- 高级品质兵种大量且多半自带强化，成为中坚力量
- 稀有品质兵种多次出现，配合圣物形成完全体联动
- 可获得圣物（高级圣物、少量稀有圣物）
- 最终构筑成型，迎接最终Boss战
- 获得Boss专属圣物

### 7.1 跨品质联动组合

不同品质兵种之间存在天然的配合关系：

> 这一跨品质联动设计确保了普通和高级品质兵种在后期仍有上场价值——它们为稀有品质兵种提供联动所需的"触发源"。

### 9.3 敌方猫设计说明

- **鼠辈**（普通）：基础近战单位，低属性但附带中毒效果，数量优势。部署于外圈
- **长矛猫**（普通）：远程分裂单位，与我方长矛猫机制相同但属性较低。部署于中圈+外圈
- **猫骑士**（高级）：重装近战单位，高生命值+霸体机制，需要集中火力击杀。部署于内圈+中圈
- **游侠**（高级）：远程控制单位，高攻击+缠绕机制，优先击杀。可部署于全区域
- **奶牛猫族长**（稀有）：BOSS级单位，极高生命值+霸体机制，需要团队配合击杀。仅部署于内圈

### 9.1 品质枚举

enum Rarity

### 9.2 强化版本

```
enum EnhanceVersion
├── Original = 0    // 原版
└── Enhanced = 1    // 强化版
```

### 9.3 类型标签枚举

```
enum TypeTag
├── Tank = 0     // 坦克
├── Warrior = 1  // 战士
└── Psyonic = 2  // 灵能
```

### 9.4 UnitConfig

```
UnitConfig {
    unitId:         单位唯一 ID
    name:           显示名
    species:        物种（Cat / Dog / Bird / Other）
    weightClass:    重量级标签（Light / Medium / Heavy，可多个）
    populationCost: 人口消耗（在 fighter_config.json 中配置）
    rarity:         品质（Rarity 枚举，0=普通/1=高级/2=稀有，固定不可变）
    enhanceVersion: 强化版本（0=原版/1=强化版）
    typeTags:       类型标签列表（如 ["tank"] 或 ["warrior", "tank"]）
    maxHp:          生命值（强化不改变）
    attack:         攻击力（强化不改变）
    attackSpeed:    攻击速度（强化不改变）
    moveSpeed:      移动速度（强化不改变）
    attackRange:    攻击距离（强化不改变）
    targetPriority: 默认目标选择（强化不改变）
    skillId:        技能 ID（原版和强化版对应不同技能效果）
    mechanismTags:  机制标签列表（如 ["split", "bounce"]，用于圣物系统匹配）
    avatarId:       外观 ID
}
```

### 9.5 招募概率配置

```
RaritySpawnConfig {
    regionId:          所属大关（1~3）
    rarity:            品质
    spawnRate:         出现概率（0.0~1.0）
    bornEnhanceRate:   天生强化概率（0.0~1.0）
}
```
