# 战斗技能 Buff 系统

版本：v2.0

---

## 一、系统概述

Buff 系统是战斗技能的核心数据载体。所有增益/减益效果（属性修改、状态效果、特殊能力）均通过统一的 Buff 结构表示，经过层级化的应用链路最终影响战斗单位的运行时属性。

---

## 二、Buff 分类

### 2.1 按生命周期分类

| 类型 | 说明 | 清除时机 |
|------|------|----------|
| **永久 Buff** | 局内成长，跨战斗永久生效 | 本局游戏结束 |
| **战斗内 Buff** | 仅当前战斗有效 | 战斗结束清零 |

> 对应数值流向中的"永久层"和"战斗层"。

### 2.2 按来源分类

| 来源 | 说明 |
|------|------|
| **命运** | 祈愿获得的属性提升 |
| **猫市** | 奇物（装备）效果 |
| **天生被动** | 兵种自带的固有被动能力 |
| **消耗品** | 一次性道具效果 |
| **抉择** | 随机事件奖励 |
| **战斗胜利** | 战斗掉落的装备效果 |

### 2.3 按影响范围分类

| 范围 | 说明 |
|------|------|
| **全体** | 所有兵种 |
| **单兵种** | 指定兵种 |
| **按标签** | 拥有指定标签的所有兵种 |

### 2.4 按应用类型分类

| 类型 | 说明 |
|------|------|
| **当前单位** | 只影响当前已有的单位 |
| **光环** | 当前单位 + 未来新获得的单位自动继承 |

### 2.5 标签系统

每个兵种可拥有多个标签，用于 Buff 的定向筛选。

| 示例标签 |
|----------|
| 橘猫、奶牛猫、狸花猫、暹罗猫、近战、远程、飞行、铁甲 |

**规则：**
- 一个兵种可以拥有多个标签
- 标签可在配置中自由扩展
- Buff 可通过标签定向影响拥有该标签的所有兵种
- 标签与兵种是多对多关系（一个标签对应多个兵种，一个兵种拥有多个标签）

## 三、Buff 叠加规则

| 规则 | 说明 |
|------|------|
| **不可叠加** | 重复添加时刷新持续时间，不增加层数 |
| **可叠加** | 每层独立计算，取较长持续时间 |
| **仅刷新时间** | 不叠加层数，只刷新持续时间 |

可叠加 Buff 有最大层数限制。

---

## 四、Buff 生命周期

### 4.1 创建

Buff 通过以下方式产生：
- 命运/抉择阶段选择效果时创建
- 装备奇物时创建
- 战斗中触发特定条件时创建（如击杀触发饱食）

### 4.2 应用

```
选择效果/装备奇物
    ↓
按影响范围分发到对应兵种
    ↓
检查是否已存在同 Buff
    ├─ 已存在 → 按叠加规则处理（叠加或刷新）
    └─ 不存在 → 新增
    ↓
如有特殊效果 → 注册效果回调
```

### 4.3 持续与 Tick

- 永久 Buff：无持续时间限制，一直生效
- 限时 Buff：每秒倒计时，到期自动移除
- 持续触发类 Buff：按固定间隔触发效果（如 DoT 伤害）

### 4.4 移除

- 按 ID 移除：卸载装备/注销选择时
- 按来源移除：移除某系统的所有 Buff
- 战斗结束清理：清除所有战斗内 Buff

## 五、状态效果系统

### 5.1 DoT（持续伤害）效果

| 效果 | 说明 | 叠加方式 |
|------|------|----------|
| **毒** | 每秒造成 DPS × 层数的伤害 | 可叠加 |
| **流血** | 每秒造成 DPS × 层数的伤害 | 可叠加 |
| **燃烧** | 每秒造成 DPS × 层数的伤害 | 可叠加 |

DoT 伤害在战斗 Tick 中直接扣减目标生命值。

### 5.2 控制效果

| 效果 | 说明 | 叠加方式 |
|------|------|----------|
| **冻结** | 定身，无法移动/攻击/施法 | 不可叠加，刷新持续时间 |
| **减速** | 移动速度降低，上限 90% | 可叠加 |
| **狩猎标记** | 受到伤害增加 | 不可叠加 |

### 5.3 战斗内成长效果

| 效果 | 触发条件 | 说明 |
|------|----------|------|
| **饱食（HP）** | 大橘击杀敌人 | 每层增加最大生命值，击杀后补血 |
| **饱食（ATK）** | 大橘击杀敌人 | 每层增加攻击力 |
| **龙语充能** | 暹罗施法 | 每层增加法术伤害百分比 |
| **猎手专注** | 狸花攻击标记目标 | 每层增加对标记目标的伤害百分比 |

> 这些效果属于"战斗层"数值，战斗结束全部清零。

## 七、属性修正体系

### 7.1 修正公式

战斗中的最终属性由基础属性 + 所有 Buff 修正计算：

```
最终攻击 = 基础攻击 × (1 + 百分比加成总和) + 固定值加成总和
最终防御 = 同理
最终生命 = 同理
最终速度 = 基础速度 × (1 + 速度百分比加成) + 速度固定值加成
最终攻速 = 基础攻速 × (1 + 攻速百分比加成)
```

### 7.2 属性颜色编码（UI 显示）

| 属性 | 颜色 |
|------|------|
| 攻击 | 红 |
| 防御 | 蓝 |
| 速度 | 金 |
| 生命 | 绿 |
| 攻速 | 橙 |
| 统御 | 紫 |

## 八、伤害公式

```
基础伤害 = MAX(攻击方攻击力 - 防御方防御力, 0)
减伤率 = MAX(1 - 防御方防御力 / (防御方防御力 + 100), 0.2)
最终伤害 = MAX(基础伤害 × 减伤率 × 技能倍率, 1) + 真实伤害
```

- **技能倍率**和**真实伤害**由 Buff 的特殊效果提供
- 减伤率下限为 20%，保证最低伤害

## 九、特殊效果系统

### 9.1 效果回调时机

Buff 可以注册以下生命周期回调：

| 回调 | 触发时机 |
|------|----------|
| **战斗开始** | Buff 首次应用时 |
| **每帧 Tick** | 持续触发类效果 |
| **攻击命中** | 攻击命中敌人时 |
| **击杀** | 击杀敌人时 |
| **死亡** | 自身死亡时 |
| **过期** | Buff 持续时间结束时 |

### 9.2 各兵种特殊效果 ID 范围

| ID 范围 | 兵种 |
|---------|------|
| 100-109 | 狸花猫 |
| 200-209 | 大橘 |
| 300-309 | 奶牛猫 |
| 400-409 | 暹罗猫 |
