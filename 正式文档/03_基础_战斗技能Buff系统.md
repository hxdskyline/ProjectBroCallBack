# 战斗技能 Buff 系统

版本：v3.0

---

## 一、系统概述

Buff 系统是战斗技能的核心数据载体。所有增益/减益效果（属性修改、状态效果、特殊能力）均通过统一的 Buff 结构表示，经过层级化的应用链路最终影响战斗单位的运行时属性。

技能体系遵循"原子单元"设计原则——每种基础技能效果是不可再拆分的底层逻辑，兵种技能、圣物效果均通过这些原子单元组合实现。

### 1.1 技能效果总览

| 体系 | 包含效果 |
|------|---------|
| 控制体系 | 减速、缠绕、沉默、眩晕、冰冻、击退、击倒、击飞、嘲讽 |
| 异常伤害体系 | 灼烧、中毒 |
| 防御体系 | 治疗、分摊 |
| 增益体系 | 吸血、霸体 |
| 特殊效果 | 分裂、弹射、召唤 |

## 二、Buff 分类

### 2.1 按生命周期分类

| 类型 | 说明 | 清除时机 |
|------|------|----------|
| **永久 Buff** | 局内成长，跨战斗永久生效 | 本局游戏结束 |
| **战斗内 Buff** | 仅当前战斗有效 | 战斗结束清零 |

> 对应数值流向中的"永久层"和"战斗层"。

### 2.2 按来源分类

| 来源 | 说明 |
|------|------|
| **命运** | 祈愿获得的属性提升 |
| **猫市** | 奇物（装备）效果 |
| **兵种技能** | 兵种自带的固有技能（与品质关联，强化可升级技能效果） |
| **消耗品** | 一次性道具效果 |
| **抉择** | 随机事件奖励 |
| **战斗胜利** | 战斗掉落的装备效果 |
| **强化** | 温泉猫薄荷精华，兵种从原版升至强化版（技能效果提升，基础属性不变） |
| **圣物** | Boss关及战斗掉落，修改游戏全局规则，增强特定机制标签 |

### 2.3 按影响范围分类

| 范围 | 说明 |
|------|------|
| **全体** | 所有兵种 |
| **单兵种** | 指定兵种 |
| **按标签** | 拥有指定标签的所有兵种 |
| **按机制标签** | 拥有指定机制标签（mechanismTag）的所有兵种 |

### 2.4 按应用类型分类

| 类型 | 说明 |
|------|------|
| **当前单位** | 只影响当前已有的单位 |
| **光环** | 当前单位 + 未来新获得的单位自动继承 |

### 2.5 标签系统

#### 类型标签

每个猫拥有**类型标签**，用于体系划分和阵容搭配：

| 标签 | 定位 | 典型特征 |
|------|------|---------|
| **坦克** | 前排承伤、嘲讽吸引火力 | 高生命值、霸体/减伤机制 |
| **战士** | 中排输出、混合功能 | 均衡属性、控制/输出兼备 |
| **灵能** | 后排输出/辅助、机制驱动 | 远程攻击、DOT/召唤/治疗等特殊机制 |

#### 机制标签

每种技能效果绑定`mechanismTag`，圣物通过标签匹配增强对应机制：

| 机制标签 | 对应效果 |
|----------|---------|
| `slow` | 减速 |
| `root` | 缠绕 |
| `silence` | 沉默 |
| `stun` | 眩晕 |
| `freeze` | 冰冻 |
| `knock_back` | 击退 |
| `knock_down` | 击倒 |
| `knock_up` | 击飞 |
| `taunt` | 嘲讽 |
| `burn` | 灼烧 |
| `poison` | 中毒 |
| `heal` | 治疗 |
| `share_damage` | 分摊 |
| `lifesteal` | 吸血 |
| `super_armor` | 霸体 |
| `split` | 分裂 |
| `bounce` | 弹射 |
| `summon` | 召唤 |

**规则：**
- 一个兵种可以拥有多个机制标签
- 标签可在配置中自由扩展
- Buff 可通过标签定向影响拥有该标签的所有兵种
- 标签与兵种是多对多关系

## 三、Buff 叠加规则

### 3.1 通用叠加规则

| 规则 | 说明 |
|------|------|
| **不可叠加** | 重复添加时刷新持续时间，不增加层数 |
| **可叠加** | 每层独立计算，取较长持续时间 |
| **仅刷新时间** | 不叠加层数，只刷新持续时间 |

可叠加 Buff 有最大层数限制。

### 3.2 控制效果叠加规则

#### 控制时间规则

同一技能的控制时间**不能叠加**——同一控制技能重复命中时，刷新持续时间而非叠加。

#### 不同控制效果叠加

同时受到**不同**控制技能时，效果互相叠加（如：同时被减速和眩晕，既无法移动也无法攻击）。

#### 相同控制效果叠加

同时受到（同一来源或不同来源）**同一**控制技能时，控制效果不能叠加，**取最高值**。

> **示例**：减速30%与减速40%同时触发时，实际效果为减速40%。

#### 控制解除规则

- 被**击飞、击退、击倒**的敌人会**解除**缠绕、冰冻、嘲讽状态
- 位移型控制会打断束缚型/仇恨型控制

#### 沉默与嘲讽互斥

- 被**嘲讽**的敌人**无法被沉默**（两种控制效果互斥，嘲讽优先级更高）

## 四、Buff 生命周期

### 4.1 创建

Buff 通过以下方式产生：
- 命运/抉择阶段选择效果时创建
- 装备奇物时创建
- 战斗中触发特定条件时创建（如兵种技能触发）
- 圣物效果应用时创建

### 4.2 应用

```
选择效果/装备奇物/触发技能
    ↓
按影响范围分发到对应兵种
    ↓
检查是否已存在同 Buff
    ├─ 已存在 → 按叠加规则处理（叠加或刷新）
    └─ 不存在 → 新增
    ↓
如有特殊效果 → 注册效果回调
```

### 4.3 持续与 Tick

- 永久 Buff：无持续时间限制，一直生效
- 限时 Buff：每秒倒计时，到期自动移除
- 持续触发类 Buff：按固定间隔触发效果（如 DoT 伤害）

### 4.4 移除

- 按 ID 移除：卸载装备/注销选择时
- 按来源移除：移除某系统的所有 Buff
- 战斗结束清理：清除所有战斗内 Buff

## 五、状态效果系统

### 5.1 控制体系

#### 减速
- **效果**：降低目标移动速度X%，持续Y秒，上限90%
- **叠加规则**：同时受到多个减速时取最高值
- **控制类型**：软控制（不影响攻击和技能释放）
- **mechanismTag**：`slow`

#### 缠绕
- **效果**：目标无法移动但可以攻击，持续X秒
- **控制类型**：中等控制（位置锁定）
- **mechanismTag**：`root`

#### 沉默
- **效果**：目标无法触发技能和被动效果，持续X秒，不影响普通攻击
- **控制类型**：软控制（技能封锁）
- **mechanismTag**：`silence`
- **特殊规则**：被嘲讽的敌人无法被沉默

#### 眩晕
- **效果**：目标原地眩晕X秒，无法行动、无法攻击
- **控制类型**：硬控制（完全剥夺行动能力，不改变位置）
- **mechanismTag**：`stun`

#### 冰冻
- **效果**：冻结敌人X秒，冻结期间无法攻击；冰冻结束后受到**破冰伤害10点**
- **控制类型**：硬控制（附带破冰伤害）
- **mechanismTag**：`freeze`

#### 击退
- **效果**：使目标远离攻击者X米，击退期间无法输出
- **控制类型**：硬控制（位移型）
- **mechanismTag**：`knock_back`

#### 击倒
- **效果**：击退+倒地的效果组合，使目标倒地X秒，倒地期间无法输出
- **控制类型**：硬控制（位移+倒地）
- **mechanismTag**：`knock_down`

#### 击飞
- **效果**：使目标离地X米，倒地X秒，倒地期间无法输出
- **控制类型**：强控制（浮空+倒地）
- **mechanismTag**：`knock_up`

#### 嘲讽
- **效果**：强制吸引1名敌方攻击自己，持续X秒
- **控制类型**：强控制（仇恨强制）
- **mechanismTag**：`taunt`

### 5.2 异常伤害体系

#### 灼烧
- **效果**：灼烧状态持续**3秒**，每秒受到**5点伤害**
- **叠加规则**：不可叠加，重复施加刷新持续时间
- **mechanismTag**：`burn`

#### 中毒
- **效果**：中毒状态持续**2秒**，每层每秒受到**1点伤害**
- **叠加规则**：默认最高叠加**3层**；不同来源的中毒效果叠加计算，不会独立计算
- **mechanismTag**：`poison`

### 5.3 防御体系

#### 治疗
- **效果**：立即回复目标X点HP
- **mechanismTag**：`heal`

#### 分摊
- **效果**：与指定友军建立连接，连接期间平均分摊受到的伤害和治疗，持续X秒
- **定位**：防御+治疗双端共享机制
- **mechanismTag**：`share_damage`

### 5.4 增益体系

#### 吸血
- **效果**：攻击伤害的X%转化为自身HP回复
- **mechanismTag**：`lifesteal`

#### 霸体
- **效果**：免疫所有控制效果，持续X秒
- **mechanismTag**：`super_armor`

### 5.5 特殊效果

#### 分裂
- **效果**：攻击时，向主目标旁边的其他敌人各发射1发额外子弹（有弹道）。旁边没有敌人则不触发
- **mechanismTag**：`split`

#### 弹射
- **效果**：攻击/技能造成伤害后，以当前敌人为发射点，寻找最近的另一名敌人再造成1次**50%**伤害
- **mechanismTag**：`bounce`

#### 召唤
- **效果**：召唤**1个骷髅猫**（独立作战单位）
- **骷髅猫属性**：继承召唤者一定比例的攻击力和血量
- **mechanismTag**：`summon`

## 六、技能联动规则

### 6.1 缠绕相关联动

- 对**缠绕**的敌人施加**击退、击倒、击飞**时，本次伤害**增加50%**（拉断伤害）

### 6.2 冰冻与灼烧联动

- 对**冰冻**的人施加**灼烧**时：立即破除冰冻状态，并受到**双倍破冰伤害（20点）**
- 对**灼烧**的人施加**冰冻**时：冰冻状态持续**0.1秒**后立刻解除，并受到**双倍破冰伤害（20点）**

> 两种触发方式均为20点伤害，形成"冰火互克"的对称设计。

### 6.3 冰冻+灼烧联动链（示例）

以冰冰猫 + 火球猫 + 对应圣物为例：

1. 冰冰猫施加冰冻（基础2秒，有「霜之哀伤」则为4秒）
2. 火球猫施加灼烧 → 触发破冰双倍伤害
3. 破冰基础伤害10点，「霜之哀伤」翻倍至20点，双倍破冰=**40点伤害**
4. 灼烧基础3秒，「火之高兴」延长至5秒，持续灼烧=**25点伤害**
5. 单次冰火联动总计**65点伤害**

### 6.4 中毒无限叠加链（示例）

以苍蝇猫 + 巫毒猫 + 「荆棘王冠」为例：

1. 苍蝇猫强化版40%概率施加中毒 + 巫毒猫弹射传播中毒
2. 「荆棘王冠」将中毒层数上限从3层→无限
3. 巫毒猫的弹射在多个中毒目标之间链式传播，每弹跳一次都有概率施加新中毒
4. 层数不受限后DPS无上限

### 6.5 分裂+弹射交叉链（示例）

以长矛猫 + 火球猫 + 铀235猫为例：

1. 铀235猫强化版提供全局光环：分裂→弹射（50%）、弹射→分裂（50%）
2. 长矛猫触发分裂 → 铀235光环触发弹射 → 弹射击中触发铀235光环→再分裂
3. 配合「史莱姆体液」双重判定，连锁反应概率大幅提升

## 七、属性修正体系

### 7.1 修正公式

战斗中的最终属性由基础属性 + 所有 Buff 修正计算：

```
最终攻击 = 基础攻击 × (1 + 百分比加成总和) + 固定值加成总和
最终防御 = 同理
最终生命 = 同理
最终速度 = 基础速度 × (1 + 速度百分比加成) + 速度固定值加成
最终攻速 = 基础攻速 × (1 + 攻速百分比加成)
```

### 7.2 属性颜色编码（UI 显示）

| 属性 | 颜色 |
|------|------|
| 攻击 | 红 |
| 防御 | 蓝 |
| 速度 | 金 |
| 生命 | 绿 |
| 攻速 | 橙 |
| 统御 | 紫 |

## 八、伤害公式

```
基础伤害 = MAX(攻击方攻击力 - 防御方防御力, 0)
减伤率 = MAX(1 - 防御方防御力 / (防御方防御力 + 100), 0.2)
最终伤害 = MAX(基础伤害 × 减伤率 × 技能倍率, 1) + 真实伤害
```

- **技能倍率**和**真实伤害**由 Buff 的特殊效果提供
- 减伤率下限为 20%，保证最低伤害

## 十、UI 显示

### 10.1 Buff 栏分组

同来源的多个 Buff 合并显示：

```
苍蝇拍x2 +40攻击力
双斧 +30%攻速
```
