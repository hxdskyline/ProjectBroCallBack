# 特殊模式

版本：v1.0

---

## 一、系统概述

特殊模式是独立于原模式的新玩法，通过主界面"特殊模式"按钮进入。核心战斗/构筑机制与原模式相同，但关卡结构、敌人配置和存档完全独立。

---

## 二、入口

主界面新增"特殊模式"按钮，点击后：
1. 切换到特殊模式独立存档
2. 加载特殊模式关卡配置
3. 初始化默认角色（橘猫 + 长矛猫）
4. 生成特殊模式地图
5. 进入选关阶段

---

## 三、关卡结构

### 3.1 总体结构

- **1 个大关**，**15 层**
- 第 1 层：固定 1 个节点（初始关）
- 第 2~14 层：每层固定 2 个节点，二选一
- 第 15 层：固定 1 个节点（Boss 关）

### 3.2 连线规则

每个节点连接下一层的**所有节点**（全连接），玩家可自由选择路径。

### 3.3 节点类型

复用现有节点类型，新增"祈愿"类型：

| 类型 | 说明 |
|------|------|
| Battle | 普通战斗 |
| EliteBattle | 精英战斗 |
| Shop | 猫市 |
| Event | 抉择 |
| HotSpring | 温泉 |
| Wish | 祈愿（新增） |
| Boss | Boss 战 |

## 五、难度系数

难度系数作为敌人属性的乘算系数：

```
实际攻击力 = 基础攻击力 × 难度系数
实际生命值 = 基础生命值 × 难度系数
```

当前所有关卡难度系数均为 1.0（不乘算），可通过修改配置调整。

## 六、存档

特殊模式使用独立存档文件 `special_playerdata.json`，与原模式 `playerdata.json` 完全独立。

切换模式时自动切换存档文件，互不影响。

## 八、实现说明

### 8.1 新增文件

| 文件 | 职责 |
|------|------|
| `special_levels_config.json` | 15 关配置（节点类型、敌人列表、难度系数） |
| `SpecialLevelConfig.cs` | 配置加载器 |
| `SpecialMapGenerator.cs` | 地图生成器（固定15层，全连接） |

### 8.2 修改文件

| 文件 | 修改 |
|------|------|
| `MapNodeType.cs` | 新增 `Wish = 6` |
| `MapPanel.cs` | Wish 节点标签和颜色 |
| `MainPanel.cs` | 新增"特殊模式"按钮 |
| `GameFlowController.cs` | 特殊模式入口、地图生成分支、难度系数应用、祈愿节点处理 |
| `DataManager.cs` | 独立存档支持 |
