# 选关系统（地图系统）

版本：v2.0
更新日期：2026-07-11

---

## 一、系统概述

选关系统是玩家在构筑完成后选择下一关的界面。地图在开局时随机生成整局（3个大关全部生成），采用**纺锤形**结构（从1个点打开分支，最后合拢到1个点），类似《杀戮尖塔》的分支路径地图。玩家可以看到当前关卡的怪物信息。

> **核心规则**：玩家通关当前层后，只能选择相邻的下一层节点，不能跨层选择，也不能回头选择已经通过节点的同层或上层节点 [1]。

### 1.1 迷雾系统

- 玩家只能看到**本层未来3层**未选择的关卡节点信息。
- 超过3层的关卡节点用迷雾封锁，不允许玩家查看。
- 玩家每次通关1层后，解锁下一层关卡迷雾，保证玩家始终能看到**下三层**关卡的内容。
- 当玩家通关**倒数第4层**（即第12层）时，解锁本大关剩余所有层迷雾（第13、14、15层全部可见）。

## 二、地图生成

### 2.1 生成时机

- 每局开局时随机生成整局地图（3个大关全部生成）。
- 每局节点生成后不可更改，新的一局游戏按规则重新刷新。

### 2.2 地图结构

一局游戏包含 **3 个大关（地区）**，每个大关固定 **15 层**：

```
═════ 大关 1（第 1~15 层）═════
第 1 层（起点） ──→ 第 2 层 ──→ ... ──→ 第 14 层 ──→ 第 15 层（Boss）
                                          │
═════ 大关 2（第 1~15 层）═════         地区切换
第 1 层（起点） ──→ 第 2 层 ──→ ... ──→ 第 14 层 ──→ 第 15 层（Boss）
                                          │
═════ 大关 3（第 1~15 层）═════         地区切换
第 1 层（起点） ──→ 第 2 层 ──→ ... ──→ 第 14 层 ──→ 第 15 层（最终Boss）
```

> **纺锤形结构**：每个大关从1个起点节点开始，逐步分支扩展，中期达到最宽，然后逐步合线，最终汇聚到1个Boss节点。

> **说明**：每个大关内部层号均独立编号为 1~15，大关之间通过地区切换衔接。全局关卡编号为第1关~第45关（3 × 15）[5]。

### 2.3 节点编号规则

每个节点编号格式为 **`x-y`**：
- `x`：层数（取值范围 1~15）
- `y`：该层第几个节点（取值范围 1~N，N为该层节点总数）

示例：`3-4` 表示第3层第4个节点。

### 2.4 节点类型

| 类型 | 说明 |
|------|------|
| 普通战斗 | 标准环形战场战斗 |
| 精英战斗 | 更强的敌人，更好的奖励 |
| 商店（猫市） | 消耗木天蓼叶购买单位、道具、增益 |
| 随机事件 | 触发特殊剧情或选择 |
| 温泉 | 强制二选一：集体泡温泉（全体单位生命值回满） 或 猫薄荷精华（选择一名兵种从0级升至1级，全属性+50%） [4] |
| Boss | 大关最终首领战 |

## 三、节点生成规则

### 3.1 特殊层节点（固定规则）

以下特殊层节点**不参与随机**，每大关固定不变：

| 层号 | 节点数量 | 节点编号 | 节点类型 |
|------|---------|----------|----------|
| 第1层 | 1个 | 1-1 | 普通战斗（起点） |
| 第14层 | 2个 | 14-1、14-2 | 温泉 × 1 + 商店 × 1（随机分配） |
| 第15层 | 1个 | 15-1 | Boss（终点） |

### 3.2 通用层节点数量分布（第2~13层，共12层）

通用层（第2~13层）的节点数量从以下三种分布中随机确定：

| 单层节点数 | 出现层数 | 说明 |
|-----------|---------|------|
| 2个节点 | 随机3层 | 哪些层为2节点，随机决定 |
| 3个节点 | 随机5层 | 哪些层为3节点，随机决定 |
| 4个节点 | 随机4层 | 哪些层为4节点，随机决定 |

> **验证**：3 + 5 + 4 = 12层 ✓

### 3.3 通用层节点类型分布（第2~13层）

每个大关（15层）共计刷新以下特殊节点类型：

| 节点类型 | 每大关总数 | 已固定分配 | 通用层剩余 | 说明 |
|----------|-----------|-----------|-----------|------|
| Boss | 1 | 15-1（1个） | 0 | 固定 |
| 温泉 | 3 | 14层（1个） | 2 | 通用层分配 |
| 商店 | 3 | 14层（1个） | 2 | 通用层分配 |
| 精英 | 3 | — | 3 | 通用层分配 |
| 随机事件 | 3 | — | 3 | 通用层分配 |

**通用层剩余特殊节点分配规则**（共10个：2温泉 + 2商店 + 3精英 + 3随机事件）：

| 层段 | 涵盖层号 | 层数 | 分配特殊节点 | 说明 |
|------|---------|------|-------------|------|
| 前段 | 第4~8层 | 5层 | 1温泉 + 1商店 + 1精英 + 1随机事件 | 共4个特殊节点分布到5层中（4层各有1个特殊节点，1层无特殊节点），具体哪个特殊节点落在哪层随机 |
| 中段 | 第9~12层 | 4层 | 1温泉 + 1商店 + 1精英 + 1随机事件 | 共4个特殊节点，每层恰好分布1个，具体哪个特殊节点落在哪层随机 |
| 后段 | 第13层 | 1层 | 1精英 + 1随机事件 | 2个特殊节点全部落在第13层 |

> **填充规则**：每层中，未被特殊节点占用的槽位，均用**普通战斗节点**填充。

### 3.4 算法约束

- 每层分配特殊节点时，需确保**特殊节点数量 ≤ 该层节点总数**。
- 若某层节点数不足以容纳分配到的特殊节点，则将溢出特殊节点顺延至同层段内有空余槽位的相邻层。
- 同一层内，各节点类型不重复。

## 四、节点连接生成规则

### 4.1 基本约束

- 每一层的每个节点，**只和相邻层**的节点相连。
- 连接方向：从低层向高层单向生成。

### 4.2 边界层连接（固定规则）

| 连接方向 | 规则 |
|----------|------|
| 第1层 → 第2层 | **1-1节点必定连接第2层所有节点** |
| 第14层 → 第15层 | **14-1、14-2节点均必定连接15-1节点** |

### 4.3 通用层连接算法（第2层→第3层 至 第13层→第14层）

对于每个发起节点 `x-y`（x = 2~13），向其上一层（x+1层）检索以下4个目标节点：

| 检索序号 | 目标节点编号 | 说明 |
|----------|-------------|------|
| 1 | (x+1)-(y-1) | 左上邻接 |
| 2 | (x+1)-y | 正上邻接 |
| 3 | (x+1)-(y+1) | 右上邻接 |
| 4 | (x+1)-(y+2) | 右侧偏移邻接 |

对每个检索到的目标节点，按以下规则判断是否建立连接：

| 目标节点已有连接数 | 连接建立概率 | 说明 |
|-------------------|-------------|------|
| 0 | **100%** | 必定建立连接 |
| 1 | **50%** | 随机判定 |
| 2 | **30%** | 随机判定 |
| ≥3 | **0%** | 不建立连接 |

**注意**：
- 对于不存在对应编号的目标节点（如 `(x+1)-0`、超出该层节点总数的编号），不建立连接。
- 连接判定从发起节点 `x-y` 开始，按 `y` 从小到大依次处理，确保已建立连接的计数实时更新。

## 五、当前关卡信息

### 5.1 显示内容

| 信息 | 说明 |

> 实现说明：街头情报等级存储在 `PlayerData.streetIntel` 中，地图节点 Tips 浮窗根据该等级显示不同精度的敌人信息 [4]。

## 六、节点选择与交互

### 6.1 点击交互

1. 玩家点击可选节点（只能选择相邻的下一层节点）。
2. 弹出 Tips 浮窗，显示该节点信息。

### 6.2 Tips 内容

| 节点类型 | Tips 显示内容 |

| 普通战斗 | 关卡名称、敌人数量（根据情报等级）、预计奖励 |

## 八、节点状态与视觉效果

### 8.1 节点状态

| 状态 | 视觉表现 | 可点击 |
|------|---------|--------|
| 已通过 | 灰色 + 勾号 | 否 |
| 当前可选 | 高亮 + 呼吸动画（仅相邻下一层节点） | 是 |

- 超过当前层3层以上的节点及连线，统一覆盖迷雾遮罩。
- 每通关一层，迷雾遮罩向后解锁一层。
- 到达第12层后，全部迷雾清除，第13~15层完全可见。

## 九、数据结构定义

### 9.1 MapData

```
MapData
├── nodes: List<MapNode>     // 所有节点列表
├── edges: List<MapEdge>     // 所有连线列表
└── currentLayer: int        // 玩家当前所在层号（1~15）
```

### 9.2 MapNode

```
MapNode
├── id: string               // 节点唯一ID（如 "2-3-1" 表示大关2第3层第1个节点）
├── layer: int               // 层号（1~15）
├── index: int               // 该层内序号（1~N）
├── nodeCode: string         // 节点编号（如 "3-4"）
├── type: NodeType           // 节点类型枚举（NormalBattle/EliteBattle/Shop/Event/HotSpring/Boss）
├── nextNodeIds: List<string> // 连接到的下一层节点ID列表
├── prevNodeIds: List<string> // 从上一层连接到本节点的节点ID列表（可选，便于回溯）
└── state: NodeState         // 节点状态枚举（Passed/Selectable/Locked/Fogged）
```

### 9.3 MapEdge

```
MapEdge
├── fromNodeId: string       // 起始节点ID
├── toNodeId: string         // 目标节点ID
└── isVisible: bool          // 是否可见（迷雾中的连线不可见）
```

### 9.4 节点类型枚举

```
enum NodeType
├── NormalBattle = 0   // 普通战斗
├── EliteBattle = 1    // 精英战斗
├── Shop = 2           // 商店（猫市）
├── Event = 3          // 随机事件
├── HotSpring = 4      // 温泉
└── Boss = 5           // Boss
```

## 十、地图生成算法（伪代码）

### 10.1 主流程

```
GenerateMap(regionIndex):
    1. 初始化 nodes = [], edges = []
    2. 调用 GenerateLayerNodeCounts()  → 确定第2~13层每层节点数
    3. 调用 GenerateSpecialLayerNodes() → 生成第1、14、15层固定节点
    4. 调用 AssignNodeTypes()          → 为第2~13层分配节点类型
    5. 调用 GenerateEdges()            → 生成所有层间连线
    6. 返回 MapData { nodes, edges }
```

### 10.2 节点数量生成

```
GenerateLayerNodeCounts():
    layerCounts = [0] × 15                    // 索引0~14，对应层号1~15
    layerCounts[0]  = 1                       // 第1层：1个节点
    layerCounts[13] = 2                       // 第14层：2个节点
    layerCounts[14] = 1                       // 第15层：1个节点
  
    // 第2~13层（索引1~12）：随机分配
    pool = [2,2,2, 3,3,3,3,3, 4,4,4,4]      // 3个2, 5个3, 4个4
    pool = Shuffle(pool)                       // 随机打乱
  
    for i = 1 to 12:
        layerCounts[i] = pool[i-1]
  
    return layerCounts
```

### 10.3 节点类型分配

```
AssignNodeTypes(layerCounts):
    // Step 1: 固定特殊层
    nodes[0][0].type = NormalBattle           // 1-1 起点
    nodes[13][0].type, nodes[13][1].type = Shuffle([HotSpring, Shop])  // 14-1, 14-2
    nodes[14][0].type = Boss                  // 15-1 Boss
  
    // Step 2: 通用层特殊节点池
    specialPool = [HotSpring, HotSpring, Shop, Shop, 
                   Elite, Elite, Elite, Event, Event, Event]
    specialPool = Shuffle(specialPool)
  
    // Step 3: 按层段分配
    // 第4~8层（索引3~7）：分配 specialPool[0~3]
    DistributeSpecials(specialPool[0:4], layers=3..7, layerCounts)
  
    // 第9~12层（索引8~11）：分配 specialPool[4~7]
    DistributeSpecials(specialPool[4:8], layers=8..11, layerCounts)
  
    // 第13层（索引12）：分配 specialPool[8~9]
    nodes[12][0].type = specialPool[8]
    nodes[12][1].type = specialPool[9]
  
    // Step 4: 剩余槽位填充普通战斗
    for layer 2..13:
        for each slot in layer:
            if slot.type is empty:
                slot.type = NormalBattle
```

### 10.4 连线生成

```
GenerateEdges(nodes):
    edges = []
  
    // 边界规则：第1层 → 第2层（全连接）
    for each node in layer[2]:
        edges.add( Edge(from=layer[1][0], to=node) )
  
    // 边界规则：第14层 → 第15层（全连接）
    for each node in layer[14]:
        edges.add( Edge(from=node, to=layer[15][0]) )
  
    // 通用层：第2层→第3层 至 第13层→第14层
    for x = 2 to 13:
        for each node x-y in layer[x]:
            targetOffsets = [-1, 0, +1, +2]           // y偏移量
            for offset in targetOffsets:
                targetY = y + offset
                targetNode = GetNode(x+1, targetY)     // 检索 (x+1)-(y+offset)
                if targetNode == null: continue        // 不存在则跳过
              
                existingConnections = CountIncomingEdges(targetNode)
              
                if existingConnections >= 3: continue   // ≥3不连接
                if existingConnections == 2: prob = 0.3
                else if existingConnections == 1: prob = 0.5
                else: prob = 1.0                       // 0→必定连接
              
                if Random() < prob:
                    edges.add( Edge(from=node, to=targetNode) )
  
    return edges
```

## 十一、UGUI 实现方案

### 11.1 核心结构

```
ScrollView (Horizontal, 无弹性)
├─ Content
│   ├─ FogLayer（迷雾遮罩层，覆盖超过3层的区域）
│   ├─ Edges父物体
│   │   └─ Edge预制体 × M条（白色1x1 Image拉伸旋转）
│   ├─ Nodes父物体
│   │   └─ Node预制体 × N个
│   └─ PlayerMarker（当前位置标记）
```

### 11.2 节点坐标计算

```
x = (layer - 1) × 列间距
y = (nodeIndex - 中心行) × 行间距
```

### 11.3 连线绘制

用 UI Image 实现每条连线：
- 宽度 = 两点距离
- 高度 = 3px（线宽）
- 位置 = 两点中点
- 旋转 = 两点角度

### 11.4 迷雾遮罩

- 使用一个半透明黑色遮罩 Image，覆盖 `(currentLayer + 3)` 层之后的所有区域。
- 遮罩位置和大小根据节点坐标动态计算。
- 每通关一层，遮罩 `x` 边界向后推移一个列间距。
