# 选关系统

版本：v1.2

---

## 一、系统概述

选关系统是玩家在构筑完成后选择下一关的界面。地图在开局时随机生成整局（3个大关），采用**纺锤形**结构（从1个点打开分支，最后合拢到1个点），类似《杀戮尖塔》的分支路径地图。玩家可以看到当前关卡的怪物信息。

> **核心规则**：玩家只能选择相邻的下一层节点，不能跨层选择。

---

## 二、地图生成

### 2.1 生成时机

- **开局时随机生成整局地图**（3个大关全部生成）
- 因为玩家能看到未来三关，所以地图必须提前生成好

### 2.2 地图结构

一局游戏包含 **3 个大关**（地区），每个大关的最后是 Boss：

```
═══ 大关 1（第 1~15 关）═══
  第 1 关 ──→ 第 2 关 ──→ ... ──→ 第 15 关（Boss）
                                    │
═══ 大关 2（第 16~30 关）═══      选择招募 → 地区切换
  第 16 关 ──→ 第 17 关 ──→ ... ──→ 第 30 关（Boss）
                                     │
═══ 大关 3（第 31~45 关）═══      选择招募 → 地区切换
  第 31 关 ──→ 第 32 关 ──→ ... ──→ 第 45 关（最终 Boss）
```

> **纺锤形结构**：每个大关从1个起点节点开始，逐步分支扩展，中期达到最宽，然后逐步合线，最终汇聚到1个Boss节点。

### 2.3 节点分布

每个大关固定 **15 层**（可配置），节点呈**纺锤形**分支路径分布（类似杀戮尖塔）：

```
层0      ○              ← 单一起点
         │
层1    ○─┼─○            ← 第0关后必然3分叉
       │ │ │
层2    ○ ○ ○            ← 3条路径并行
       │ │ │
层3    ○─┼─○            ← 某条路径产生2分叉
       │   │
层4    ○   ○
       │ │ │
层5    ○ ○ ○            ← 温泉节点（固定）
       │ │ │
层6    ○─┼─○            ← 又一个2分叉
       │   │
层7    ○   ○
         │
层8      ○              ← 开始合线
         │
层9    ○─┼─○            ← 部分路径合并
       │ │ │
层10   ○ ○ ○            ← 温泉节点（固定）
         │
层11     ○              ← 进一步合拢
         │
层12   ○─┼─○
       │ │ │
层13   ○ ○ ○            ← 最终层前
         │
层14    👹              ← Boss（固定单节点）
```

**分布规则**：
- 第0关后必然产生 **3分叉**
- 平均每 3~4 层产生一个 **2分叉**
- 中期开始逐步合线，路径数量减少
- 最终聚拢到 Boss 关（单节点）
- 每层有 2~4 个节点
- **温泉节点固定在第5层和第10层**（每地区2个）

> **纺锤形结构**：起点1个节点 → 分支扩展 → 中期最宽 → 合线收缩 → 终点1个Boss节点。

### 2.4 节点类型

| 类型 | 说明 |
|------|------|
| **普通战斗** | 标准环形战场战斗 |
| **精英战斗** | 更强的敌人，更好的奖励 |
| **商店（猫市）** | 消耗木天蓼叶购买单位、道具、增益 |
| **随机事件** | 触发特殊剧情或选择 |
| **温泉** | 二选一：回复所有单位50%生命值 或 永久提升指定单位全属性50% |
| **Boss** | 大关最终首领战 |

> **节点类型分布**：节点类型的固定分布存储在 `map_config.json` 中，所有地区共用一个配置文件。温泉节点固定在第5层和第10层。

## 四、当前关卡信息

### 4.1 显示内容

选关界面显示当前关卡的详细信息：

| 信息 | 说明 |
|------|------|
| **关卡编号** | 当前关卡的编号 |
| **关卡类型** | 普通战斗/商店/事件/Boss |
| **敌人信息** | 根据街头情报等级显示 |
| **预计奖励** | 通关可获得的奖励 |

### 4.2 敌人信息显示

敌人信息根据主角"街头情报"等级显示，在**Tips浮窗中展示**：

| 等级 | 显示内容 |
|------|----------|
| Lv.0 | 不显示任何敌方信息 |
| Lv.1 | 模糊描述（"少量敌人"、"大量敌人"） |
| Lv.2 | 大致范围（"敌人约 10-20 只"） |
| Lv.3 | 精确数字 + 敌方首领头像 |

> **实现说明**：街头情报等级存储在 `PlayerData.streetIntel` 中，地图节点Tips浮窗根据该等级显示不同精度的敌人信息。

## 六、节点选择

### 6.1 点击交互

1. 玩家点击可选节点（只能选择相邻的下一层节点）
2. 弹出 Tips 浮窗，显示该节点信息
3. Tips 上有"进入"按钮
4. 玩家点击"进入"后，根据节点类型跳转：
   - **战斗/精英** → 战斗准备阶段
   - **商店** → 构筑界面（猫市）
   - **事件** → 构筑界面（抉择）
   - **温泉** → 弹出温泉二选一界面（回复50%生命 或 永久提升指定单位全属性50%）
   - **Boss** → 战斗准备阶段

### 6.2 Tips 内容

| 节点类型 | Tips 显示内容 |
|----------|--------------|
| **普通战斗** | 关卡名称、敌人数量（根据情报等级）、预计奖励 |
| **精英战斗** | 关卡名称、精英敌人信息、高额奖励预览 |
| **商店** | 商店名称、可购买物品预览 |
| **随机事件** | 事件名称、事件描述 |
| **温泉** | "温泉：回复50%生命 或 永久提升全属性50%" |
| **Boss** | Boss名称、Boss头像、首领信息、专属奖励 |

## 九、UGUI 实现方案

### 9.1 核心结构

```
ScrollView (Horizontal, 无弹性)
  └─ Content
       ├─ Edges父物体
       │    └─ Edge预制体 × M条（白色1x1 Image拉伸旋转）
       ├─ Nodes父物体
       │    └─ Node预制体 × N个
       └─ PlayerMarker（当前位置标记）
```

### 9.2 数据结构

```
MapData {
    nodes:  所有节点列表
    edges:  所有连线列表
}

MapNode {
    id:           节点唯一ID
    column:       列号（0~14）
    row:          行号
    type:         节点类型（战斗/精英/商店/事件/Boss）
    nextNodeIds:  连接到的下一层节点ID列表
}

MapEdge {
    fromNodeId:  起始节点ID
    toNodeId:    目标节点ID
}
```

### 9.3 地图生成算法（纺锤形）

```
1. 生成起点（层0，1个节点）
2. 生成3分叉（层1，3个节点，每个连到起点）
3. 循环层2~13：
   - 层5和层10固定为温泉节点
   - 随机决定是否2分叉（约30%概率）
   - 随机决定是否合线（概率随层号递增，体现纺锤形）
4. 生成Boss（层14，1个节点，连到上一层所有节点）
```

> **纺锤形实现**：前半段（层0-7）主要做分叉扩展，后半段（层8-14）主要做合线收缩，体现纺锤形结构。

### 9.4 连线绘制

用 UI Image 实现每条连线：
- 宽度 = 两点距离
- 高度 = 3px（线宽）
- 位置 = 两点中点
- 旋转 = 两点角度

### 9.5 节点坐标计算

```
x = column × 列间距
y = (row - 中心行) × 行间距
```

### 9.6 节点状态

| 状态 | 视觉 | 可点击 |
|------|------|--------|
| 已通过 | 灰色 + 勾号 | 否 |
| 当前可选 | 高亮 + 呼吸动画 | 是 |
| 未到达 | 暗色 + 锁定 | 否 |

### 9.7 滚动定位

玩家可以手动滚动 ScrollView 查看地图，选择节点后不会自动滚动。
