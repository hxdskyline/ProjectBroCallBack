# 数值流向

版本：v4.1

---

## 一、游戏结构概览

| 项目 | 数值 | 说明 |
|------|------|------|
| 总关卡数 | 45 关 | 3 个区域 × 15 层（可配置） |
| 区域数 | 3 | 每区域含 15 层 + Boss |
| Boss 战 | 3 场 | 每区域最后一层 |
| 兵种重量级 | 轻量级 / 中量级 / 重量级 | 标签，可多个，存储在 fighter_config.json 的 weightClass 字段 |
| 兵种品质 | 普通 / 高级 / 稀有 | 固定不可变，定义不同种族猫的整体品质 |
| 兵种类型标签 | 坦克 / 战士 / 灵能 | 可多个 |
| 人口占用 | 在 fighter_config.json 中配置 | 每个兵种独立配置 |
| 人口上限 | 主角「领导力」决定 | 初始值 3，每升一级 +1 |
| 三区系统 | 待上阵区 / 上阵区 / 生产区 | 单位管理分区（生产区不可逆） |
| 通用货币 | 木天蓼叶 | 贯穿全局 |
| 主角属性 | 等级、领导力、街头情报、咪格魅力 | 存储在 PlayerData 中 |

---

## 二、数值分层

游戏中的数值分为四层：

| 层级 | 名称 | 生命周期 | 说明 |
|------|------|----------|------|
| **局外层** | 跨局成长 | 多局游戏 | 声望解锁内容（兵种/事件/奖励） |
| **永久层** | 局内成长 | 整局游戏（45 关） | 祝福效果、装备加成、属性提升、**强化版本**、**圣物效果** |
| **层内效果** | 层内效果 | 单关 | 命运限时 buff、消耗品效果 |
| **战斗层** | 战斗内成长 | 单场战斗 | 中毒层数、灼烧状态、冰冻状态、眩晕、缠绕、霸体等 |

## 三、各来源的数值归属

| 来源 | 获得的数值类型 | 归属层级 | 说明 |
|------|--------------|----------|------|
| **命运** | 兵种属性提升（绝对值/百分比） | 永久层 | 本局永久生效 |
| **命运** | 祝福（被动效果） | 永久层 | 本局永久生效 |
| **命运** | 装备（奇物） | 永久层 | 装备效果持续生效 |
| **命运** | 木天蓼叶 | 货币 | 即时持有 |
| **命运** | 限时 buff | 层内效果 | 持续指定关卡数 |
| **抉择** | 各类奖励（道具/木天蓼叶/属性/装备） | 按选项不同 | 永久或限时 |
| **猫市** | 奇物（装备） | 永久层 | 装备效果持续生效 |
| **猫市** | 兵种 | 永久层 | 兵种永久加入待上阵区 |
| **猫市** | 消耗品（一次性道具） | 层内效果 | 使用后消失 |
| **战斗招募** | 兵种 | 永久层 | 掷骰子招募，进入待上阵区 |
| **战斗结算** | 木天蓼叶 | 货币 | 胜利获得全额关卡奖励，失败获得一半 |
| **战斗胜利** | 装备/消耗品（概率掉落） | 永久层/层内效果 | 按类型判定 |
| **兵种技能** | 兵种固有能力 | 永久层/战斗层 | 兵种自带，按触发条件生效 |
| **消耗品** | 一次性数值效果 | 层内效果 | 使用后消失 |
| **生产区产出** | 木天蓼叶 | 货币 | 每关自动结算 |
| **温泉（猫薄荷精华）** | 兵种强化（原版→强化版） | 永久层 | 技能效果提升，基础属性不变 |
| **圣物** | 机制标签增强 | 永久层 | 增强特定机制标签，影响所有匹配兵种 |
| **Boss关** | 稀有品质兵种三选一 | 永久层 | 击败Boss后选择稀有兵种 |
| **Boss关** | Boss圣物 | 永久层 | 击败Boss后获得Boss专属圣物 |

## 五、关键数值流向规则

### 5.1 兵种属性流向

```
兵种基础属性（配置初始值，强化不改变）
  │
  ├─→ 兵种技能（原版/强化版不同效果）──→ 按触发条件生效
  ├─→ 命运提升（+绝对值或×百分比）──→ 永久生效
  ├─→ 祝福效果（+绝对值或×百分比）──→ 永久生效
  ├─→ 装备/奇物加成 ──→ 永久生效
  ├─→ 强化版本（技能效果提升，基础属性不变）──→ 永久生效
  ├─→ 圣物效果（机制标签增强）──→ 永久生效
  │
  └─→ 战斗前最终计算 ──→ 战斗内使用
                          │
                          ├─→ 层内限时 buff ──→ 仅本关
                          └─→ 战斗内 buff ──→ 仅本场战斗
```

### 5.2 战斗内层数流向

```
战斗开始 → 层数从 0 开始
  │
  ├─→ 施法/攻击命中 → 层数/状态增长
  │     （中毒层数、灼烧状态、冰冻状态、眩晕、缠绕、霸体等）
  │
  └─→ 战斗结束 → 所有层数/状态清零
                  │
                  └─→ 下一场战斗重新从 0 开始
```

### 5.3 生产区产出流向

```
生产区单位驻守
  │
  └─→ 每关结算 → 产出木天蓼叶
                  │
                  └─→ 自动加入持有量
```

### 5.4 人口管理

```
主角领导力 → 决定人口上限（初始值 3）
  │
  └─→ 各兵种人口占用（在 fighter_config.json 中配置）
      │
      └─→ 总上阵人口 ≤ 领导力上限
```

## 六、货币流向

### 6.1 木天蓼叶来源

```
木天蓼叶来源：
  ├─ 初始木天蓼叶（200）
  ├─ 战斗胜利奖励（按区域和节点类型，100~300）
  ├─ 战斗失败奖励（胜利奖励的一半）
  ├─ 看板掉落（每秒10个 + 摧毁爆发100个）
  ├─ 命运奖励
  ├─ 猫市卖出道具/装备
  ├─ 抉择奖励
  └─ 生产区单位产出（每关自动结算）
```

### 6.2 木天蓼叶消耗

```
木天蓼叶消耗：
  ├─ 命运消耗（可配置多档位）
  ├─ 猫市购买（奇物/消耗品/兵种）
  └─ 猫市刷新（递增消耗）
```

### 6.3 木天蓼叶存量影响

- 木天蓼叶是唯一通用货币，贯穿全局
- 猫市刷新消耗递增，鼓励理性消费
- 生产区产出提供稳定收入来源，降低对战斗奖励的单一依赖
- 战斗产出与节点类型绑定（普通/精英/Boss），精英和Boss奖励更高

## 七、Buff 来源汇总

| 来源 | Buff 类型 | 持续时间 | 获取方式 |
|------|----------|----------|----------|
| 命运 | 属性提升 / 祝福 / 装备 | 永久（整局） | 命运事件 |
| 命运 | 限时 buff | 指定关卡数 | 命运事件（特定选项） |
| 抉择 | 各类奖励 | 按选项不同 | 抉择事件 |
| 猫市 | 装备（奇物） | 永久（整局） | 猫市购买 |
| 猫市 | 消耗品 | 一次性 | 猫市购买 |
| 战斗招募 | 兵种 | 永久（整局） | 掷骰子招募 |
| 战斗胜利 | 装备/消耗品 | 按类型 | 概率掉落 |
| 兵种技能 | 兵种固有能力 | 永久/战斗内 | 兵种自带 |
| 消耗品 | 一次性数值效果 | 一次性 | 购买或获得后使用 |
| 生产区产出 | 木天蓼叶 | 每关自动 | 生产区单位驻守 |
| 温泉（猫薄荷精华） | 兵种强化（技能效果提升） | 永久（整局） | 温泉二选一 |
| 圣物 | 机制标签增强 | 永久（整局） | 战斗掉落/Boss关 |
| Boss关 | 稀有品质兵种 | 永久（整局） | 击败Boss三选一 |
| Boss关 | Boss圣物 | 永久（整局） | 击败Boss获得 |
