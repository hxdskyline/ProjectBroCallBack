# 招募系统

版本：v1.1

---

## 一、系统概述

招募是战斗胜利后触发的环节。玩家对敌方兵种进行掷骰子招募，成功则获得新单位。属于**战斗后环节，不可跳过**。

> **重要规则**：战斗胜利后**立即**进入招募环节，招募完成后才能继续后续流程（构筑/选关）。

---

## 二、触发时机

| 时机 | 触发条件 | 说明 |
|------|----------|------|
| **战斗胜利后** | 战斗胜利 | **立即**对敌方兵种进行掷骰子招募 |

> **实现说明**：战斗胜利后，`RecruitmentDiceSystem` 会被调用，生成招募卡片并显示掷骰子界面。招募完成后，玩家才能进入构筑或选关阶段。

---

## 三、招募流程

```
战斗胜利
  │
  ├─ 显示招募界面
  │    ├─ 对方有几个兵种 → 出几张卡片
  │    └─ 每张卡片显示：兵种名、头像、特性、人口占用、金币花费
  │
  ├─ 掷骰子动画
  │    ├─ 每张卡片依次掷骰子
  │    ├─ 彩色 = 可招募
  │    └─ 黑白 = 不可招募
  │
  ├─ 玩家选择招募
  │    ├─ 可招募单位：玩家点击确认招募
  │    └─ 不可招募单位：自动跳过
  │
  └─ 招募完成
       └─ 可招募单位进入待上阵区
```

---

## 四、卡片信息

每张招募卡片显示以下信息：

| 信息 | 说明 |
|------|------|
| **兵种名** | 该兵种的显示名称 |
| **头像** | 该兵种的头像图标 |
| **特性** | 该兵种的标签和特性描述 |
| **人口占用** | 该兵种占用的人口数（在 fighter_config.json 中配置） |
| **金币花费** | 招募该兵种需要花费的木天蓼叶数量 |

---

## 五、掷骰子机制

### 5.1 掷骰子动画

- 每张卡片依次进行掷骰子动画
- 动画效果：骰子旋转 → 停止 → 显示结果
- 结果：彩色（成功）或 黑白（失败）

### 5.2 成功率计算

成功率基于 fighter 的属性（具体字段待设计确认）：

```
招募成功率 = 基础概率 + 主角"咪格魅力"加成
```

- 基础概率：由关卡难度和兵种稀有度决定
- 主角"咪格魅力"：提升招募概率

### 5.3 掷骰子结果

| 结果 | 颜色 | 说明 |
|------|------|------|
| **成功** | 彩色 | 该兵种可招募 |
| **失败** | 黑白 | 该兵种不可招募 |

---

## 六、招募确认

### 6.1 可招募单位

- 玩家点击确认招募按钮
- 该单位进入待上阵区
- 招募需要花费金币（木天蓼叶）

### 6.2 不可招募单位

- 自动跳过，无需操作
- 招募界面显示"不可招募"提示

---

## 七、招募结果处理

### 7.1 成功招募

- 新单位进入待上阵区
- 玩家可在自由阶段管理该单位（放入上阵区或生产区）

### 7.2 招募失败

- 无任何变化
- 该兵种不会加入我方

---

## 八、特殊规则

### 8.1 Boss 关

- Boss 关胜利后，所有敌方单位均可招募（成功率提升）
- Boss 关专属奖励可能包含额外招募机会

### 8.2 多兵种关卡

- 敌方有多个兵种时，每个兵种独立掷骰子
- 玩家可选择招募部分或全部可招募单位

---

## 九、历史记录

### 9.1 产生记录

每次招募完成后，产生一条历史记录，包含：发生回合、系统类型、敌方兵种列表、玩家招募的兵种。

### 9.2 读取记录

- **本系统读取**：可读取历史记录避免重复出现相同事件
- **其他系统读取**：流程条目的条件触发可检查本系统的历史（如"曾招募过某兵种"）

### 9.3 存储位置

统一存储在全局历史日志中，按回合和系统类型索引（参考 01 文档第十节）。
